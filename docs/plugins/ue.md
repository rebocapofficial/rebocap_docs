<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">

Restart the editor and open `Edit → Plugins`; if the list shows <strong>Rebocap - blueprint control</strong> (version V3), the plugin is installed.

</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">

</div>

</div>
</div>

<div class="ue-doc-subsec">

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">

</div>
<div style="flex: 1.5; min-width: 250px;">

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Create a Map Data asset from the default value](/img/ue_plugin/guide/05_map_asset.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

Drag the variable into the graph and compile once; under `Default Value` click `+` to create a Map Data asset.

</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">

<div style="flex: 1.5; min-width: 250px;">

Fill in the character's bone names one by one. `Select Bone Preset` fills UE's default names in one click; if your rig uses different names, check the Skeleton window and copy them over.

</div>

<p class="ue-doc-h" role="heading" aria-level="3" id="rebocap-body-pose">Rebocap Body Pose</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Rebocap Body Pose node](/img/ue_plugin/nodes/body_pose_node.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

Drives the character skeleton from the 24 Rebocap mocap nodes in real time. This is the main node of the plugin: it reads the LiveLink subject, converts the mocap transforms through the bone mapping asset and writes them into the pose.

Drop it just before `Output Pose`, set a `Retarget Asset`, and the character follows the mocap stream.

</div>
</div>
<p style="margin: 6px 0 0; font-size: 13px; color: var(--ifm-color-emphasis-600);">Figure 2 — the node title shows [60 Hz] and [Connected] while streaming.</p>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">Pins</p>

| Pin | Type | Default | Description |
| --- | --- | --- | --- |
| `Auto Submit Skeleton Data` | bool | true | On first connect, sends the character T-Pose skeleton (24 bones + foot contact points) back to Rebocap |
| `Connect Rebocap` | bool | true | Whether the node connects automatically; disable to connect only from the panel or Blueprint |
| `Enable Frame Interpolation` | bool | false | Interpolates between mocap frames when the render rate is higher than the mocap rate |
| `Interpolation Speed` | float | 45 | Interpolation speed (1–120); higher follows the stream more tightly |
| `Hold Pose On Dropout` | bool | true | Keeps the last valid pose when packets are missing instead of snapping to T-Pose |
| `Show Viewport Debug HUD` | bool | false | Shows mocap rate, viewport FPS and connection state in the top-left corner |
| `Retarget Asset` | class | `RebocapMapData` | Bone mapping asset used to retarget the 24 mocap nodes |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">Details panel</p>

| Setting | Default | Description |
| --- | --- | --- |
| `LiveLink Subject Name` | rebocap | Subject name; separates devices or editor instances |
| `Dropout Timeout (s)` | 2.0 | How long the last pose is held before it is released |
| `Stale Frame Timeout (s)` | 0.25 | A frame older than this counts as dropped; without it a disconnect freezes the pose forever |
| `Resume Blend (s)` | 0.15 | Blend window when the stream comes back, even with interpolation disabled |
| `Throttle Skeleton Registration` | false | Experimental: registers the skeleton at most once every 2 s |
| `Zero-Alloc Static Subject` | false | Experimental: skips redundant static-skeleton allocations |
| `Optimize Frame Evaluation` | false | Experimental: caches the LiveLink role to reduce lock contention |
| `Show Controlled Bones` | true | Highlights driven bones in the preview viewport |
| `Joint Color` / `Link Color` | cyan / magenta | Colors for joints and bone links |
| `Joint Radius` / `Link Thickness` | 2.2 / 1.6 | Size of joints and links |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">Usage</p>

1. Right-click in an AnimGraph and search for `Rebocap Body Pose`.
2. Connect it just before `Output Pose`.
3. Create or pick a `RebocapMapData` asset and fill in the 24 bones.
4. Compile; expect only warnings for bones your skeleton does not have.
5. Run PIE — the control panel should show about 60 Hz.

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">Notes</p>

- The rest pose must be **T-Pose**; for A-Pose characters put `Rebocap A-Pose to T-Pose` before this node.
- `Auto Submit Skeleton Data` only reads foot vertices in the editor, so ground contact is slightly worse in packaged builds.
- Without a `Retarget Asset` the built-in preset is used, which requires matching bone names.

</div>

</div>
<div class="ue-doc-sec">

<p class="ue-doc-h" role="heading" aria-level="3" id="rebocap-a-pose-to-t-pose">Rebocap A-Pose to T-Pose</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Rebocap A-Pose to T-Pose node](/img/ue_plugin/nodes/a2t_node.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

Converts an A-Pose base pose into T-Pose so `Rebocap Body Pose` can drive it correctly. Intended for MetaHuman, VRoid, MMD and Mixamo characters whose rest pose is A-Pose.

</div>
</div>
<p style="margin: 6px 0 0; font-size: 13px; color: var(--ifm-color-emphasis-600);">Figure 3 — `Alpha` blends the conversion in and out.</p>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">Pins</p>

| Pin | Type | Default | Description |
| --- | --- | --- | --- |
| `Base Pose` | Pose | — | Base pose coming from the rest of the graph |
| `Retarget Asset Override (Pin)` | class | none | Optional pin override for the mapping asset |
| `Alpha` | float | 1.0 | Blend weight: 0 leaves the pose untouched, 1 applies the full conversion |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">Details panel</p>

| Setting | Default | Description |
| --- | --- | --- |
| `Select Preset Template` | UE5 Manny/Quinn/MetaHuman | Fills all 20 bone offsets; also MMD (~40°), VRoid/VRM (~40°), Mixamo (~45°), Custom |
| `Symmetrical Edit` | true | Edit the left side only; the right side mirrors automatically |
| `Invert Roll / Pitch / Yaw` | false | Flips an axis while mirroring |
| `Retarget Asset` | none | Shared with `Rebocap Body Pose` |
| `Use Retarget Asset Bones` | true | Pulls bone names from the asset on every refresh |
| `1. Left Arm` … `5. Root & Spine & Head` | 0° | Per-bone local rotation offsets |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">The 20 bones</p>

| Group | Bones |
| --- | --- |
| 1. Left Arm | left collar, upper arm, lower arm, wrist |
| 2. Right Arm | right collar, upper arm, lower arm, wrist |
| 3. Left Leg | left thigh, calf, ankle |
| 4. Right Leg | right thigh, calf, ankle |
| 5. Root & Spine & Head | pelvis, spine 1–3, neck, head |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">Notes</p>

- Offsets are **local rotation angles**, not absolute angles; presets are starting points.
- Selecting the node highlights the adjusted bones in the viewport (green/gold for A2T).

</div>

</div>

<p class="ue-doc-h" role="heading" aria-level="3" id="parameter-quick-reference">Parameter quick reference</p>

| Symptom | Likely cause | Fix |
| --- | --- | --- |
| Character does not move | No `Retarget Asset`, or an empty mapping | Create a `RebocapMapData` and fill all 24 bones |
| Warning about `spine_04` / `spine_05` | UE4 mannequin has only three spine bones | Use the UE4 preset (`spine_01/02/03`) |
| Stepping or jitter | Render rate higher than the mocap rate | Enable `Enable Frame Interpolation` |
| Flash when disconnecting | Old version reconnected automatically | Upgrade to V3 |
| Pose freezes after disconnect | Old version kept re-evaluating the last frame | Upgrade to V3 (`Stale Frame Timeout`) |
| Jump when the stream resumes | First frame applied in one step | Raise `Resume Blend (s)` to 0.15–0.3 |
| Custom port never connects | Mocap app is not listening on it | Falls back to 7690 in ~4.5 s |
| Feet float after packaging | Foot vertices unavailable at runtime | Known limitation |
