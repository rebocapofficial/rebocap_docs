### SteamVR {#software-download-toc}
<h2 class="tutorial-heading-flag" style="background: #aab0ff; margin-top: 0; display: inline-block;">SteamVR</h2>


<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![steamvr_play_area](../../static/img/steamvr_guide/steamvr_play_area%20-en.jpg)

</div>
<div style="flex: 1.5; min-width: 250px;">

- Disable the SteamVR boundary<br />
The default boundary restricts the maximum movement range of tracking points, acting like an invisible wall.<br />
If the VR headset is incorrectly positioned at a height of 2.4 meters, raising your legs while lying down might show trackers unable to exceed the headset's height,<br />
because SteamVR's default ceiling height is 2.4 meters, and tracking points cannot pass through the ceiling.

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![steamvr_reset_vr](../../static/img/steamvr_guide/steamvr_reset_vr.jpg)

</div>
<div style="flex: 1.5; min-width: 250px;">

- Recenter VR headset orientation in advance<br />
Press and hold the 'Right Controller Home Button' to reset VR headset system orientation,<br />
which resets the SteamVR virtual horizon arrow to face straight ahead. If orientation is accidentally lost, use this feature to realign the coordinate system.

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![steamvr_binding_prompt_pops](../../static/img/steamvr_guide/steamvr_binding_prompt_pops.jpg)

</div>
<div style="flex: 1.5; min-width: 250px;">

Select any community binding configuration in the background,<br />
and after activating it, the prompt will no longer appear on subsequent launches.

</div>

## Show and Hide SteamVR Trackers




<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![steamvr_windows](../../static/img/steamvr_guide/v01_off_1-en.png)

</div>
<div style="flex: 1.5; min-width: 250px;">
<strong> Show and hide tracking points</strong><br />
 Control the visibility of tracking points in the software's [ Configure SteamVR Output Nodes ] section.<br />
 There is no need to configure this in the SteamVR management menu.<br />

 <details className="plain-details"><summary>Note</summary>
The trackers are not directly connected to SteamVR. The physical trackers manipulate the skeleton system, and corresponding tracking points are created on the skeleton system to input into SteamVR.<br />
This means even without a physical tracker for a specific point, tracking points can still be provided to SteamVR.

</details>


</div>
</div>

## Tracker role attributes set but the game cannot recognize feet and waist

- Some games use the openVR environment to recognize tracking, but the current rebocap V01/V02 SteamVR driver has a bug where it cannot be recognized due to the missing [Relo] name,<br />
Even if the corresponding attributes are modified in SteamVR, they still cannot be recognized.<br />
The current workaround is to replace it with the older driver_rebocap.dll file.

This bug is awaiting a fix by the development team in a future update.

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![p05dll](../../static/img/steamvr_guide/p05dll.jpg)

</div>
<div style="flex: 1.5; min-width: 250px;">

<a href="/img/steamvr_guide/(%20P05%20)%20%20%20%20driver_rebocap.dll" download target="_blank" class="button button--primary button--sm" style="margin-bottom: 15px; display: inline-block; font-size: 1em;">Download ( P05 ) driver_rebocap.dll</a><br />

- Replacement process:<br />
1 - Keep rebocap and SteamVR closed.<br />
2 - Go to the rebocap installation folder,<br />
Find the "Rebocap\data\rebocap_driver\bin\win64" folder,<br />
Replace the driver_rebocap.dll file in it.<br />
(Remove the "P05" prefix)<br />
3 - First start the Rebocap software, wait for it to update the SteamVR driver file, and then start SteamVR.

</div>
</div>
