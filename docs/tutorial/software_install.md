## Software Update Notes

### Changelog

#### 2026-11-11 Update

**Firmware**
1. 📡 Receiver firmware V8:
    > Dropped the traditional CDC serial port driver and switched to vendor mode, giving a faster transfer rate (basically no impact),<br> mainly because the serial port driver is easily disturbed by other programs on the system, or affected by system components, and its stability is too poor.<br>Note: Once upgraded to the new firmware, only the latest software version can be used. Older versions cannot recognize it, and the receiver firmware must be rolled back to use older software.

2. ◼️ Tracker firmware V16:
    > Fixed the inconsistent default orientation between the new and old algorithms (with v15 firmware, the tracker faces 90° to the right after a button restart),<br>added support for non-anti-magnetic mode (previously the anti-magnetic switch had no effect on v15 firmware, making it unsuitable for dancing).

**Software**
1. Added Linux and Android versions, mainly to observe whether users encounter core bugs, and changed the operation logic of some UI
    > The Linux UI stays consistent with Windows; the Android UI is redesigned, but its interaction flow remains close to Windows, and it supports switching between portrait and landscape.

2. Replaced the 3D viewer with OGRE
    > However, NVIDIA graphics card drivers may normalize GPU usage, incorrectly showing GPU usage of 20%~40%; AMD graphics cards do not have this "wondrous" display, which awaits further investigation and adjustment.

3. Firmware upgrade is now a separate window
    >Upgrading firmware from v7 to v15 was a hurdle for many people, hence this window was improved.

4. [Six-axis mode] renamed to [Geomagnetic assist], and the switch is inverted
    >Players in every language were found to mistake 6-axis for a 6-tracker mode.

5. Motion calibration logic adjusted
    >Added an [Emergency Stop] button, so you can stop if calibration is triggered by mistake.<br>Added a collapsible extension panel; after appropriate adjustment the calibration countdown becomes very short, and the previous calibration record can be retained (if not enabled, it expires 7 minutes after the software is closed).

6. Tracker knock changed to [Tap assignment]
    > Allows players to customize tap macros, freely choosing whom to tap, the tap interval, and which shortcut to trigger.

7. Added a volume slider
    > Makes it convenient to turn the software notification sounds on or off directly.

8. Fixed the VMC height offset bug
    > The previous bug where VMC was higher than the ground was because the ground-to-hips height was incorrectly output at 2x.

9. Removed the [Advanced Settings] control for some frequently used features
  

**end.** UI interaction improvements will continue, and there are still many items from the usage feedback statistics that need adjustment.



#### 2026-02-04 Update: Rebocap Release V02 Beta02
1. Updated firmware to v15, optimized anti-magnetic and 6-axis algorithms, improved anti-magnetic stability, improved 6-axis stability
   > Under dynamic conditions, e.g., dancing continuously in a poor magnetic environment, performance is still close to that of 6-axis mode.    > By default, calibration is limited to 8 sensors at a time. If you add the file: `data/__no_limit_max_nodes__` in the data directory, the limit will be removed
