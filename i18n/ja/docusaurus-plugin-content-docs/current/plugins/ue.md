<p class="ue-doc-h" role="heading" aria-level="3">1. UE プロジェクトへ導入</p>

![rebocap フォルダをプロジェクトの Plugins ディレクトリに配置](/img/ue_plugin/guide/01_install_plugins.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

プラグインの圧縮ファイルを解凍し、中の `rebocap` フォルダをプロジェクトのルートにある `Plugins` フォルダへそのまま入れてください。プロジェクトに `Plugins` フォルダが無い場合は、新しく作成します。

エディタを再起動し、`編集 → プラグイン` を開きます。一覧に <strong>Rebocap - blueprint control</strong>（バージョン V3）が表示されていればインストール完了です。

</div>

LiveLink で対応する Rebocap の接続ポートを確認できます。

</div>
</div>

<p class="ue-doc-h" role="heading" aria-level="3">2. アニメーションブループリントで使用</p>

<p>以下では UE 標準の人形（Mannequin）を例に説明します。</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">

コンテンツブラウザでキャラクターのスケルタルメッシュを右クリックし、`作成 → アニメーションブループリント` を選んで、そのキャラクターのアニメーションブループリントを新規作成するか、既存のものを開きます。

</div>
</div>

<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">ボーンマッピング（Map Data）の設定</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![変数の型に Rebocap Map Data（クラス参照）を選択](/img/ue_plugin/guide/04_variable_class.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

左側の変数パネルで `+` を押して変数を作成し、型の検索欄で `Rebocap` を検索して `Rebocap Map Data` を選び、さらに `クラス参照`（Class Reference）を選択します。

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![デフォルト値から Map Data アセットを作成](/img/ue_plugin/guide/05_map_asset.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

変数をグラフへドラッグして一度コンパイルし、右側の `デフォルト値` で `+` を押すと Map Data アセットを新規作成できます。

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Rebocap のボーンマッピングウィンドウ](/img/ue_plugin/guide/06_bone_mapping.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

マッピングウィンドウで、キャラクターに対応するボーン名を 1 つずつ入力します。`ボーン プリセットを選択` を使えば UE の既定の命名をワンクリックで入力できます。キャラクターのボーン命名が異なる場合は、スケルトンウィンドウを開いて確認し、そのままコピーしてきてください。

</div>
</div>

</div>

<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">重要 · キャラクターを T-Pose に調整</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![アニメーションブループリントに A-Pose to T-Pose ノードを追加](/img/ue_plugin/guide/07_a2t_node.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

キャラクター自体が T-Pose であれば、この手順は省略できます。そうでない場合は `Rebocap A-Pose to T-Pose` ノードを使い、アニメーションブループリント内で直接 T-Pose に調整してください。

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![A-Pose to T-Pose ノードの Retarget Asset 設定](/img/ue_plugin/guide/08_a2t_details.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

このノードは一般的なスケルトンを自動で認識し、`Retarget Asset` を手動で指定することもできます。その他のタイプの A-Pose は手動で微調整し、手と脚が視覚的に明確に T-Pose になるようにしてください。

</div>
</div>

</div>

<p style="margin: 6px 0 0; font-size: 13px; color: var(--ifm-color-emphasis-600);">図 1：モーションキャプチャデータがキャラクターに届くまで。</p>

<div class="ue-doc-sec">

<p class="ue-doc-h" role="heading" aria-level="3" id="rebocap-body-pose">Rebocap Body Pose</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Rebocap Body Pose ノード](/img/ue_plugin/nodes/body_pose_node.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

Rebocap の 24 個のモーションキャプチャノードをキャラクターのボーンへリアルタイムに反映するプラグインのメインノードです。LiveLink のサブジェクトを読み取り、ボーンマッピングアセットを介して変換したうえでポーズへ書き込みます。

`Output Pose` の直前に接続し、`Retarget Asset` を指定すれば、キャラクターがモーションキャプチャに追従します。

</div>
</div>
<p style="margin: 6px 0 0; font-size: 13px; color: var(--ifm-color-emphasis-600);">図 2：正常に受信しているときは、タイトルに [60 Hz]、[Connected] と表示されます。</p>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">ピン</p>

| ピン | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `Auto Submit Skeleton Data` | bool | true | 初回接続時にキャラクターの T-Pose スケルトン（24 ボーン + 足底の点）を Rebocap へ送り返します |
| `Connect Rebocap` | bool | true | ノードが自動で接続するかどうか。オフにするとパネルまたはブループリントから手動で接続するしかありません |
| `Enable Frame Interpolation` | bool | false | レンダリングのフレームレートがモーションキャプチャより高い場合に補間し、階段状のカクつきを抑えます |
| `Interpolation Speed` | float | 45 | 補間速度（1–120）。大きいほど追従が速くなります |
| `Hold Pose On Dropout` | bool | true | パケット欠落時に最後の有効なポーズを保持し、T-Pose へのスナップを防ぎます |
| `Show Viewport Debug HUD` | bool | false | 左上にモーションキャプチャのフレームレート、ビューポート FPS、接続状態を表示します |
| `Retarget Asset` | class | `RebocapMapData` | ボーンマッピングアセット |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">詳細パネル</p>

| パラメータ | 既定値 | 説明 |
| --- | --- | --- |
| `LiveLink Subject Name` | rebocap | LiveLink のサブジェクト名。複数デバイスや複数インスタンスを区別します |
| `Dropout Timeout (s)` | 2.0 | 最後のポーズを保持する最大時間 |
| `Stale Frame Timeout (s)` | 0.25 | フレームの経過時間がこの値を超えたらフレーム落ちとみなします。切断後に永久にフリーズするのを防ぎます |
| `Resume Blend (s)` | 0.15 | 切断から復帰したときのブレンド時間 |
| `Throttle Skeleton Registration` | false | 実験的機能：スケルトン登録を最大 2 秒間隔に制限します |
| `Zero-Alloc Static Subject` | false | 実験的機能：重複する静的スケルトンの割り当てをスキップします |
| `Optimize Frame Evaluation` | false | 実験的機能：LiveLink のロールをキャッシュし、ロック競合を軽減します |
| `Show Controlled Bones` | true | プレビュービューポートで駆動対象のボーンをハイライトします |
| `Joint Color` / `Link Color` | シアン / マゼンタ | ジョイントとリンクの色 |
| `Joint Radius` / `Link Thickness` | 2.2 / 1.6 | ジョイントの半径とリンクの太さ |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">使用手順</p>

1. アニメーショングラフ内で右クリックし、`Rebocap Body Pose` を検索します。
2. `Output Pose` の直前に接続します。
3. `RebocapMapData` を新規作成するか指定し、24 本のボーンを入力します。
4. コンパイルし、想定内の「ボーンが見つからない」という警告だけが出ていることを確認します。
5. PIE を実行し、コントロールパネルに約 60 Hz と表示されていれば正常です。

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">注意</p>

- 既定のポーズは必ず <strong>T-Pose</strong> にしてください。A-Pose のキャラクターは前段に `Rebocap A-Pose to T-Pose` を接続します。
- `Auto Submit Skeleton Data` の足底頂点はエディタ内でしか取得できないため、パッケージ化後は接地の精度がやや落ちます。
- `Retarget Asset` を指定しない場合は組み込みプリセットが使われるため、ボーン名が異なる場合は自分でアセットを作成する必要があります。

</div>

</div>
<div class="ue-doc-sec">

<p class="ue-doc-h" role="heading" aria-level="3" id="rebocap-a-pose-to-t-pose">Rebocap A-Pose to T-Pose</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Rebocap A-Pose to T-Pose ノード](/img/ue_plugin/nodes/a2t_node.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

A-Pose のベースポーズを T-Pose に変換し、`Rebocap Body Pose` が正しく駆動できるようにします。MetaHuman、VRoid、MMD、Mixamo など、既定のポーズが A-Pose のキャラクターが対象です。

</div>
</div>
<p style="margin: 6px 0 0; font-size: 13px; color: var(--ifm-color-emphasis-600);">図 3：`Alpha` で変換のブレンド率を制御します。</p>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">ピン</p>

| ピン | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `Base Pose` | Pose | — | 前段から渡されるベースポーズ |
| `Retarget Asset Override (Pin)` | class | なし | 任意：ピンでマッピングアセットを一時的に上書きします |
| `Alpha` | float | 1.0 | ブレンド率：0 で変更なし、1 で完全に変換します |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">詳細パネル</p>

| パラメータ | 既定値 | 説明 |
| --- | --- | --- |
| `Select Preset Template` | UE5 Manny/Quinn/MetaHuman | 20 本のボーンオフセットをワンクリックで入力します。MMD（約 40°）、VRoid/VRM（約 40°）、Mixamo（約 45°）、Custom も選択できます |
| `Symmetrical Edit` | true | 左側だけを編集し、右側は自動でミラーします |
| `Invert Roll / Pitch / Yaw` | false | ミラー時に軸ごとに反転します |
| `Retarget Asset` | なし | `Rebocap Body Pose` と共用します |
| `Use Retarget Asset Bones` | true | 更新のたびにアセットのボーン名で上書きします |
| `1. Left Arm` … `5. Root & Spine & Head` | 0° | 20 本のボーンのローカル回転オフセット |

<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">20 本のボーンのグループ</p>

| グループ | ボーン |
| --- | --- |
| 1. Left Arm | 左鎖骨、左上腕、左前腕、左手首 |
| 2. Right Arm | 右鎖骨、右上腕、右前腕、右手首 |
| 3. Left Leg | 左大腿、左下腿、左足首 |
| 4. Right Leg | 右大腿、右下腿、右足首 |
| 5. Root & Spine & Head | 骨盤、脊椎 1–3、首、頭 |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">注意</p>

- オフセットは <strong>ローカル回転角度</strong>であり、絶対角度ではありません。プリセットはあくまで初期値です。
- ノードを選択すると、調整対象のボーンがプレビュービューポートでハイライトされます（A2T は青緑／金色）。

<p class="ue-doc-h" role="heading" aria-level="3" id="parameter-quick-reference">パラメータ早見表とよくある質問</p>

| 現象 | よくある原因 | 対処 |
| --- | --- | --- |
| キャラクターが動かない | `Retarget Asset` が未指定、またはマッピングが未設定 | `RebocapMapData` を新規作成し、24 本のボーンをすべて入力する |
| `spine_04` / `spine_05` が見つからないと警告が出る | UE4 の人形は脊椎が 3 節しかない | UE4 用プリセット（spine_01/02/03）に切り替える |
| カクつき、階段状の動き | レンダリングのフレームレートがモーションキャプチャより高い | `Enable Frame Interpolation` をオンにする |
| 切断時に一瞬元の姿勢に戻る | 旧バージョンが自動再接続していた | V3 にアップグレードする |
| 切断後にポーズが固まる | 旧バージョンが最後のフレームを返し続けていた | V3 にアップグレードする（`Stale Frame Timeout`） |
| 復帰の瞬間にポーズが跳ぶ | 最初のフレームをそのまま適用していた | `Resume Blend (s)` を 0.15–0.3 に上げる |
| カスタムポートに接続できない | モーションキャプチャ側が待ち受けていない | 約 4.5 秒で 7690 に自動フォールバックする |
| パッケージ化後に足底が浮く | 実行時に足底の頂点が取得できない | 既知の制限 |
