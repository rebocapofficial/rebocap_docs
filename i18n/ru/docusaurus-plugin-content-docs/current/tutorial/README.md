## ⚠️ 2. Важное замечание (Калибровка магнитного поля)

- Калибровка магнитного поля имеет решающее значение для обеспечения точности пространственного отслеживания. Рекомендуется выполнять калибровку магнитного поля **после первой зарядки** или всякий раз, когда вы **перемещаетесь в новое помещение**.
- Подробные инструкции по калибровке и меры предосторожности см. здесь: 👉 **[Вопросы и ответы по магнитному полю и руководство по калибровке](../QA/magnet)**

:::danger Меры предосторожности при калибровке магнитного поля
- Калибровку магнитного поля необходимо освоить, а меры предосторожности очень важны. Если не соблюдать меры предосторожности, точность калибровки будет нарушена.
- Калибровку магнитного поля можно выполнять неоднократно в любое время. Если вы испытываете дрейф, сначала попробуйте заново откалибровать магнитное поле.
:::

:::danger Устранение неполадок и советы по производительности
Для обеспечения оптимальной работы захвата движения или при возникновении проблем обязательно ознакомьтесь с подробным текстовым руководством:
- Ориентация трекера ступни и натяжение ремешка существенно влияют на контакт с полом и устойчивость к скольжению;
- В условиях сильных магнитных помех проверьте, нужно ли включить антимагнитный режим;
- Когда трекеры ступней не надеты, проверьте, включить ли AI Engine для автоматического прогнозирования позы;
- Если у вас есть дополнительные вопросы, не стесняйтесь задавать их в [Сообществе и поддержке](../README#community).
:::
