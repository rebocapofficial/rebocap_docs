# Сертификаты, связанные с батареями

## Сертификация IEC62133 и UN38.3

Международный сертификат стандарта безопасности для продуктов с литиевыми батареями, применимый к большинству стран и регионов *Сертификация завершена, ожидается добавление двух титульных страниц сертификата*
