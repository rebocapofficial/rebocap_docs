# Функция 3D предварительного просмотра
- **Отображение предварительного просмотра захвата движения в реальном времени**

  **Инструкции**
  * Перемещайте вид левой кнопкой мыши
  * Перетаскивайте положение камеры средней кнопкой мыши, что означает перетаскивание вида
  * Колесико мыши перемещает положение камеры вперед и назад в соответствии с текущим направлением, что можно использовать для настройки размера персонажей в представлении
- **Отображение трекера**
    > Область, отмеченная как 1 на изображении `3d_preview`, используется для отображения трекера. Если трекер выбран, он может отображать направление трекера в реальном времени. Нажатие на кнопку с флажком закроет предварительный просмотр трекера в реальном времени.

<a id="how_to_close_3d_preview"></a>

### Как закрыть 3D для экономии производительности
* Нажмите кнопку в области 2 изображения `3d_preview`, чтобы приостановить рендеринг, что может сэкономить ресурсы
* Чтобы полностью закрыть 3D-рендеринг: Вы можете напрямую отключить 3D-рендеринг на странице конфигурации, что вступит в силу после перезапуска, сэкономив память и значительно сократив ресурсы ЦП и графического процессора
