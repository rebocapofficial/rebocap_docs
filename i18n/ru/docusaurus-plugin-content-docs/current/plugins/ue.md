<p style="margin: 6px 0 0; font-size: 13px; color: var(--ifm-color-emphasis-600);">Рис. 1. Как данные мокапа попадают на персонажа.</p>

<div class="ue-doc-sec">

<p class="ue-doc-h" role="heading" aria-level="3" id="rebocap-body-pose">Rebocap Body Pose</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Узел Rebocap Body Pose](/img/ue_plugin/nodes/body_pose_node.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

Управляет костями персонажа в реальном времени по 24 точкам мокапа Rebocap. Это основной узел плагина: он читает Subject LiveLink, пересчитывает трансформы через ассет маппинга костей и записывает их в позу.

Поставьте его непосредственно перед `Output Pose` и укажите `Retarget Asset` — персонаж начнёт повторять движения мокапа.

</div>
</div>
<p style="margin: 6px 0 0; font-size: 13px; color: var(--ifm-color-emphasis-600);">Рис. 2. При нормальном приёме потока в заголовке узла отображаются [60 Hz] и [Connected].</p>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">Пины</p>

| Пин | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `Auto Submit Skeleton Data` | bool | true | При первом подключении отправляет в Rebocap скелет персонажа в T-Pose (24 кости и точки стоп) |
| `Connect Rebocap` | bool | true | Подключается ли узел автоматически; если выключить, подключение возможно только из панели или из Blueprint |
| `Enable Frame Interpolation` | bool | false | Интерполяция между кадрами мокапа, когда частота рендера выше частоты мокапа; убирает ступенчатость |
| `Interpolation Speed` | float | 45 | Скорость интерполяции (1–120): чем выше значение, тем точнее узел следует за потоком |
| `Hold Pose On Dropout` | bool | true | При потере пакетов сохраняет последнюю валидную позу и не сбрасывается в T-Pose |
| `Show Viewport Debug HUD` | bool | false | Показывает в левом верхнем углу частоту мокапа, FPS вьюпорта и состояние подключения |
| `Retarget Asset` | class | `RebocapMapData` | Ассет маппинга костей, по которому ретаргетируются 24 точки мокапа |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">Панель Details</p>

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `LiveLink Subject Name` | rebocap | Имя Subject LiveLink; различает устройства и экземпляры редактора |
| `Dropout Timeout (s)` | 2.0 | Как долго удерживается последняя поза до сброса |
| `Stale Frame Timeout (s)` | 0.25 | Кадр старше этого значения считается потерянным; без этой настройки после отключения поза замирает навсегда |
| `Resume Blend (s)` | 0.15 | Длительность перехода при восстановлении потока, в том числе с выключенной интерполяцией |
| `Throttle Skeleton Registration` | false | Экспериментально: регистрация скелета не чаще одного раза в 2 с |
| `Zero-Alloc Static Subject` | false | Экспериментально: пропускает повторные аллокации статического скелета |
| `Optimize Frame Evaluation` | false | Экспериментально: кэширует роль LiveLink и снижает конкуренцию за блокировки |
| `Show Controlled Bones` | true | Подсвечивает управляемые кости во вьюпорте предпросмотра |
| `Joint Color` / `Link Color` | cyan / magenta | Цвета суставов и связей между ними |
| `Joint Radius` / `Link Thickness` | 2.2 / 1.6 | Размер суставов и толщина связей |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">Порядок использования</p>

1. В AnimGraph щёлкните правой кнопкой и найдите `Rebocap Body Pose`.
2. Подключите узел перед `Output Pose`.
3. Создайте или выберите ассет `RebocapMapData` и заполните все 24 кости.
4. Скомпилируйте; должны остаться только предупреждения о костях, которых нет в скелете.
5. Запустите PIE — панель управления должна показывать около 60 Hz.

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">Примечания</p>

- Поза покоя должна быть <strong>T-Pose</strong>; для персонажей в A-Pose поставьте перед этим узлом `Rebocap A-Pose to T-Pose`.
- `Auto Submit Skeleton Data` читает вершины стоп только в редакторе, поэтому в собранном билде контакт с землёй немного хуже.
- Если `Retarget Asset` не указан, используется встроенный пресет — он требует совпадения имён костей.

</div>

</div>
<div class="ue-doc-sec">

<p class="ue-doc-h" role="heading" aria-level="3" id="rebocap-a-pose-to-t-pose">Rebocap A-Pose to T-Pose</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Узел Rebocap A-Pose to T-Pose](/img/ue_plugin/nodes/a2t_node.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

Преобразует базовую позу A-Pose в T-Pose, чтобы `Rebocap Body Pose` мог корректно ей управлять. Подходит для персонажей MetaHuman, VRoid, MMD, Mixamo и других, у которых поза покоя — A-Pose.

</div>
</div>
<p style="margin: 6px 0 0; font-size: 13px; color: var(--ifm-color-emphasis-600);">Рис. 3. `Alpha` задаёт вес смешивания при преобразовании.</p>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">Пины</p>

| Пин | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `Base Pose` | Pose | — | Базовая поза, приходящая из предыдущей части графа |
| `Retarget Asset Override (Pin)` | class | пусто | Необязательно: переопределяет ассет маппинга через пин |
| `Alpha` | float | 1.0 | Вес смешивания: 0 — поза не меняется, 1 — применяется полное преобразование |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">Панель Details</p>

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `Select Preset Template` | UE5 Manny/Quinn/MetaHuman | Подставляет все 20 смещений костей одним нажатием; также доступны MMD (около 40°), VRoid/VRM (около 40°), Mixamo (около 45°), Custom |
| `Symmetrical Edit` | true | Правка только левой стороны, правая зеркалируется автоматически |
| `Invert Roll / Pitch / Yaw` | false | Инвертирует ось при зеркалировании |
| `Retarget Asset` | пусто | Общий с `Rebocap Body Pose` |
| `Use Retarget Asset Bones` | true | При каждом обновлении берёт имена костей из ассета |
| `1. Left Arm` … `5. Root & Spine & Head` | 0° | Локальные смещения поворота для 20 костей |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">Группы 20 костей</p>

| Группа | Кости |
| --- | --- |
| 1. Left Arm | левая ключица, плечо, предплечье, запястье |
| 2. Right Arm | правая ключица, плечо, предплечье, запястье |
| 3. Left Leg | левое бедро, голень, голеностоп |
| 4. Right Leg | правое бедро, голень, голеностоп |
| 5. Root & Spine & Head | таз, позвоночник 1–3, шея, голова |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">Примечания</p>

- Смещения — это <strong>локальные углы поворота</strong>, а не абсолютные углы; пресеты задают только начальные значения.
- При выборе узла во вьюпорте подсвечиваются кости, к которым применены смещения (у A2T — зелёный и золотистый).

<p class="ue-doc-h" role="heading" aria-level="3" id="parameter-quick-reference">Краткий справочник параметров и частые вопросы</p>

| Симптом | Вероятная причина | Что делать |
| --- | --- | --- |
| Персонаж не двигается | Не указан `Retarget Asset` или маппинг пуст | Создайте `RebocapMapData` и заполните все 24 кости |
| Предупреждение о `spine_04` / `spine_05` | У манекена UE4 всего три кости позвоночника | Используйте пресет UE4 (`spine_01/02/03`) |
| Дрожание, ступенчатость | Частота рендера выше частоты мокапа | Включите `Enable Frame Interpolation` |
| Мигание при отключении | Старая версия переподключалась автоматически | Обновитесь до V3 |
| Поза замирает после отключения | Старая версия продолжала возвращать последний кадр | Обновитесь до V3 (`Stale Frame Timeout`) |
| Рывок в момент восстановления | Первый кадр применяется сразу | Увеличьте `Resume Blend (s)` до 0.15–0.3 |
| Пользовательский порт не подключается | Приложение мокапа не слушает этот порт | Примерно через 4,5 с автоматически откатывается на 7690 |
| Стопы висят в воздухе после упаковки | Во время выполнения вершины стоп недоступны | Известное ограничение |
