# Использование VMC
Протокол VMC очень прост в использовании. После калибровки вы можете включить протокол VMC, [подробности смотрите здесь](../../ui_help_doc/control/connect#cal_pc_panel), а затем настроить прием в другом программном обеспечении. VMC — это универсальный протокол захвата движений, [подробности смотрите здесь](https://protocol.vmc.info/english.html).

Если вы стример и не уверены, поддерживает ли ваше программное обеспечение `rebocap`, пожалуйста, проверьте, поддерживает ли ваше ПО протокол VMC. Если ваше ПО его не поддерживает, вы можете обратиться к разработчику, чтобы использовать предоставленный нами [SDK](../../SDK/README) для интеграции, или напрямую использовать предоставленные нами [плагины](../../plugins/plugins) для интеграции.

:::info Примечания для пользователей протокола VMC


Пользователям протокола VMC настоятельно рекомендуется загрузить скелет. Если это модель VRM, вы можете напрямую загрузить скелет в rebocap, [здесь находится руководство по загрузке скелета](../../ui_help_doc/control/skeleton_setting#skeleton_import). Пользователи других форматов могут использовать [плагин Blender для экспорта скелета](../../plugins/blender#skeleton_export). Экспортированный файл представляет собой файл JSON и может быть изменен вручную.

Если вам неясно, как сделать то или другое, вам нужно знать высоту скелета вашего виртуального персонажа и настроить масштаб VMC (vmc scale). Установите его так, чтобы высота в rebocap * vmc_scale = текущая высота виртуального персонажа, но этот эффект, как правило, не идеален.

:::
