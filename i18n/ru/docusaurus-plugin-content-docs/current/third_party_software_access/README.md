# Другие интеграции

### [Виртуальные прямые трансляции Yunjing](https://fancyjing.com/home)

- Введение
> "Виртуальные прямые трансляции Yunjing" (Yunjing Virtual Live Streaming) — это бесплатный инструмент для виртуальных прямых трансляций в 3D, разработанный Linjing Technology. Имея только мобильный телефон или компьютер с камерой, вы можете осуществлять захват движений лица, верхней части тела и всего тела, и он уже интегрировал устройство захвата движений `Rebocap` для точного отслеживания движений. Встроена богатая коллекция реквизита, танцевальных анимаций и игрового процесса, что предоставляет VTуберам более удобные услуги для прямых трансляций.  
>
> Примечание: Если вы столкнетесь с растяжением бюста или талии модели, пожалуйста, попросите моделлерa настроить скелет. Обычно это вызвано тем, что кость бюста модели чиби (стиль `Q`) масштабируется не в соответствии с сеткой (mesh).

- Видеоурок
> [Нажмите здесь для просмотра](https://www.bilibili.com/video/BV1z7hFzfEw6)

- Документация по интеграции
- Присоединяйтесь к группе `QQ`, чтобы связаться с официальной службой поддержки; номер группы можно найти [внизу веб-страницы](https://fancyjing.com/home)


### [Виртуальные трансляции Haojia Yihe](https://sk157zmgy6.feishu.cn/docx/RK4yduZF1oEhuQxKI8scu4h2nYg)
> Гильдия трансляций Haojia Yihe (Haojia Yihe Live Guild) — это профессиональное агентство, обслуживающее стримеров в сфере развлечений, голосового чата, ACG и виртуального сектора. Оно предоставляет комплексные профессиональные операционные услуги онлайн и офлайн, включая обучение стримеров, настройку сцены трансляции, создание виртуальных персонажей и индивидуальное операционное планирование для стримеров. Профессиональная команда дополнительно расширяет возможности новой виртуальной волны, предлагая высококачественные услуги по созданию виртуальных персонажей полного цикла как для C-сегмента (B2C), так и для B-сегмента (B2B). Возглавляемая старшими техническими художниками (Technical Artists), команда объединяет планирование интеллектуальной собственности (IP), дизайн, эксплуатацию, производство и программирование в единое подразделение технической поддержки.

- Документация по интеграции
- Свяжитесь напрямую со студией Haojia Yihe
