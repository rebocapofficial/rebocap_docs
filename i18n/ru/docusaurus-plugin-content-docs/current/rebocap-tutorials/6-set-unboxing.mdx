- Откройте окно журнала (Log Window), чтобы увидеть фактическую версию прошивки каждого трекера <br />

&emsp;&emsp;🟦Синий: Трекер получает данные прошивки<br />

&emsp;&emsp;⬜Белый: Обновление успешно (обычно автоматически перезапускается через 10с; если нет, перезапустите вручную)<br />
