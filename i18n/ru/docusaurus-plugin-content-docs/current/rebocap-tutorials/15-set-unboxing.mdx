- Откройте окно журнала, чтобы просмотреть фактическую версию прошивки каждого трекера <br /> 
  (окно журнала находится в разделе "Подключить и выключить" (Connect and Power Off) в программе).

- Трекеры обновляются по беспроводной сети 📶 — USB-кабель для передачи данных не требуется.<br />

  Если обновление трекера не удалось, подумайте об отключении половины трекеров, чтобы стабилизировать загрузку данных. Трекеры с правильной версией прошивки в журналах можно оставить выключенными.

  &emsp;&emsp;🟦Синий свет: Трекер получает данные прошивки<br /> 
  &emsp;&emsp;🟨Желтый свет: Ошибка обновления (вручную нажмите кнопку 🔘 для перезапуска, затем обновите снова)<br /> 
  &emsp;&emsp;⬜Белый свет: Обновление успешно (обычно перезапускается автоматически через 10с; если автоматический перезапуск не удался, требуется ручной перезапуск)<br /> 

- Когда обновление 📡приемника завершено, отключите и снова вставьте USB, затем 🔄перезапустите программу.
