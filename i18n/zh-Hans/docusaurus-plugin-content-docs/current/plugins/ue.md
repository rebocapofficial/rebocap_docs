</div>

</div>

在内容浏览器里右键角色的骨骼网格体，选择 `创建 → 动画蓝图`，新建或进入这个角色的动画蓝图。

</div>
</div>

<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">设置骨骼映射（Map Data）</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![变量类型选择 Rebocap Map Data（类引用）](/img/ue_plugin/guide/04_variable_class.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

在左侧变量栏点 `+` 新建一个变量，类型搜索 `Rebocap`，选择 `Rebocap Map Data`，再选 `类引用`（Class Reference）。

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![在默认值里新建 Map Data 资产](/img/ue_plugin/guide/05_map_asset.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

把变量拖进图表并编译一次，右侧 `默认值` 里点 `+`，新建一个 Map Data 资产。

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Rebocap 骨骼映射窗口](/img/ue_plugin/guide/06_bone_mapping.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

在映射窗口里逐项填入角色对应的骨骼名称。`选择骨骼预设` 可以一键填入 UE 默认命名；如果角色骨骼命名不同，打开骨架窗口查看后复制过来。

</div>
</div>

</div>

<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">重要 · 把角色调整为 T-Pose</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![在动画蓝图中添加 A-Pose to T-Pose 节点](/img/ue_plugin/guide/07_a2t_node.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

角色本身就是 T-Pose 的话，可以跳过这一步。否则用 `Rebocap A-Pose to T-Pose` 节点，直接在动画蓝图里把角色调整为 T-Pose。

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![A-Pose to T-Pose 节点的 Retarget Asset 设置](/img/ue_plugin/guide/08_a2t_details.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

该节点能自动识别一些常见骨骼，也可以手动指定 `Retarget Asset`；其他类型的 A-Pose 可以手动微调，让手、腿在视觉上明确呈 T-Pose。

</div>
</div>

</div>

<p class="ue-doc-h" role="heading" aria-level="3" id="rebocap-body-pose">Rebocap Body Pose</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Rebocap Body Pose 节点](/img/ue_plugin/nodes/body_pose_node.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

把 Rebocap 的 24 个动捕节点实时驱动到角色骨骼上，是插件的主节点：读取 LiveLink 主题，经骨骼映射资产换算后写入姿势。

把它接在 `Output Pose` 之前，指定 `Retarget Asset`，角色即跟随动捕。

</div>
</div>
<p style="margin: 6px 0 0; font-size: 13px; color: var(--ifm-color-emphasis-600);">图 2：正常收流时标题显示 [60 Hz]、[Connected]。</p>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">引脚</p>

| 引脚 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `Auto Submit Skeleton Data` | bool | true | 首次连接时把角色 T-Pose 骨架（24 骨 + 脚底点）回传给 Rebocap |
| `Connect Rebocap` | bool | true | 节点是否自动连接；关闭后只能由面板或蓝图手动连接 |
| `Enable Frame Interpolation` | bool | false | 渲染帧率高于动捕帧率时做插值，消除阶梯感 |
| `Interpolation Speed` | float | 45 | 插值速度（1–120），越大越跟手 |
| `Hold Pose On Dropout` | bool | true | 掉包时保持最后有效姿势，避免闪回 T-Pose |
| `Show Viewport Debug HUD` | bool | false | 左上角显示动捕帧率、视口 FPS 与连接状态 |
| `Retarget Asset` | class | `RebocapMapData` | 骨骼映射资产 |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">细节面板</p>

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `LiveLink Subject Name` | rebocap | LiveLink 主题名，多设备/多实例时区分 |
| `Dropout Timeout (s)` | 2.0 | 保持最后姿势的最长时间 |
| `Stale Frame Timeout (s)` | 0.25 | 帧龄超过该值视为掉帧，避免断开后永久冻结 |
| `Resume Blend (s)` | 0.15 | 掉线恢复时的过渡时间 |
| `Throttle Skeleton Registration` | false | 实验项：骨架注册最多 2 秒一次 |
| `Zero-Alloc Static Subject` | false | 实验项：跳过重复的静态骨架分配 |
| `Optimize Frame Evaluation` | false | 实验项：缓存 LiveLink 角色，降低锁竞争 |
| `Show Controlled Bones` | true | 预览视口高亮被驱动的骨骼 |
| `Joint Color` / `Link Color` | 青 / 品红 | 关节点与连线颜色 |
| `Joint Radius` / `Link Thickness` | 2.2 / 1.6 | 关节点半径与连线粗细 |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">使用步骤</p>

1. 动画蓝图里右键搜索 `Rebocap Body Pose`；
2. 接到 `Output Pose` 之前；
3. 新建或指定一份 `RebocapMapData`，填好 24 个骨骼；
4. 编译，确认只有预期内的"找不到骨骼"警告；
5. PIE 运行，控制面板显示约 60 Hz 即正常。

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">注意</p>

- 默认姿势必须是 **T-Pose**；A-Pose 角色请在前一级接 `Rebocap A-Pose to T-Pose`。
- `Auto Submit Skeleton Data` 的脚底顶点只在编辑器里能取到，打包后接地略差。
- 不指定 `Retarget Asset` 时用内置预设，骨骼名不同就必须自建资产。

</div>

</div>
<div class="ue-doc-sec">

<p class="ue-doc-h" role="heading" aria-level="3" id="rebocap-a-pose-to-t-pose">Rebocap A-Pose to T-Pose</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Rebocap A-Pose to T-Pose 节点](/img/ue_plugin/nodes/a2t_node.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

把 A-Pose 基础姿势转成 T-Pose，供 `Rebocap Body Pose` 正确驱动。适用于 MetaHuman、VRoid、MMD、Mixamo 等默认 A-Pose 的角色。

</div>
</div>
<p style="margin: 6px 0 0; font-size: 13px; color: var(--ifm-color-emphasis-600);">图 3：`Alpha` 控制转换的混合权重。</p>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">引脚</p>

| 引脚 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `Base Pose` | Pose | — | 来自前级的基础姿势 |
| `Retarget Asset Override (Pin)` | class | 空 | 可选：用引脚临时覆盖映射资产 |
| `Alpha` | float | 1.0 | 混合权重：0 不修改，1 完全转换 |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">细节面板</p>

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `Select Preset Template` | UE5 Manny/Quinn/MetaHuman | 一键填入 20 骨偏移；另有 MMD（约 40°）、VRoid/VRM（约 40°）、Mixamo（约 45°）、Custom |
| `Symmetrical Edit` | true | 只改左侧，右侧自动镜像 |
| `Invert Roll / Pitch / Yaw` | false | 镜像时按轴翻转 |
| `Retarget Asset` | 空 | 与 `Rebocap Body Pose` 共用 |
| `Use Retarget Asset Bones` | true | 每次刷新时用资产覆盖骨骼名 |
| `1. Left Arm` … `5. Root & Spine & Head` | 0° | 20 根骨骼的局部旋转偏移 |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">20 根骨骼分组</p>

| 分组 | 骨骼 |
| --- | --- |
| 1. Left Arm | 左锁骨、左上臂、左前臂、左手腕 |
| 2. Right Arm | 右锁骨、右上臂、右前臂、右手腕 |
| 3. Left Leg | 左大腿、左小腿、左脚踝 |
| 4. Right Leg | 右大腿、右小腿、右脚踝 |
| 5. Root & Spine & Head | 骨盆、脊椎 1–3、颈、头 |

</div>

<p class="ue-doc-h" role="heading" aria-level="3" id="parameter-quick-reference">参数速查与常见问题</p>

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 角色不动 | 未指定 `Retarget Asset`，或映射为空 | 新建 `RebocapMapData` 并填满 24 骨 |
| 报找不到 `spine_04` / `spine_05` | UE4 人偶只有 3 节脊椎 | 换成 UE4 预设（spine_01/02/03） |
| 抖动、阶梯感 | 渲染帧率高于动捕帧率 | 打开 `Enable Frame Interpolation` |
| 断开时闪一下 | 旧版本自动重连 | 升级到 V3 |
| 断开后姿势卡住 | 旧版本一直返回最后一帧 | 升级到 V3（`Stale Frame Timeout`） |
| 恢复瞬间跳变 | 首帧直接赋值 | 调大 `Resume Blend (s)` 到 0.15–0.3 |
| 自定义端口连不上 | 动捕端未监听 | 约 4.5 秒自动回退 7690 |
| 打包后脚底浮空 | 运行时取不到脚底顶点 | 已知限制 |
