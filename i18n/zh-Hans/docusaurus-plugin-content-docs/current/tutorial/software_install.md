## 软件安装

<div class="os-switch-install os-switch-install-win">

1. 双击 rebocap_release_v01.exe（当前版本为 rebocap_release_v01.exe）
2. 按照下图所示进行安装
3. 打开 rebocap 软件
   * 开始菜单打开
   * 桌面快捷方式打开

![安装步骤](../../../../../static/img/setup_steps.gif)

</div>

<div class="os-switch-install os-switch-install-linux">

Linux 版使用 `.run` 安装包：

1. 在安装包所在目录打开终端，先赋予执行权限：`chmod +x rebocap-linux-preview-0.1-1.run`
2. 运行安装程序：`./rebocap-linux-preview-0.1-1.run`
3. 按提示完成安装，默认安装路径为 `~/.local/opt/rebocap`
4. 安装完成后，从应用菜单或安装目录启动 Rebocap

为了确保自动系统授权失败时能手动补上：

**设备权限配置（必做，否则接收器连不上）**

```bash
sudo bash ~/.local/opt/rebocap/linux/install_linux_permissions.sh --install --user "$USER"
```

执行后拔插一次接收器，再启动软件。

</div>

<div class="os-switch-install os-switch-install-android">

Android 版使用 `.apk` 安装包：

1. 将 `ReboCapAndroid-Preview-0.1.apk` 传输到手机并点击安装
2. 如系统提示，请允许“安装未知应用”
3. 安装完成后打开 Rebocap
4. 使用 OTG 数据线连接 USB 接收器，并按软件提示完成连接

</div>

## 软件更新说明

### 更新日志

#### 2026-11-11 更新

**固件**
1. 📡接收器固件 V8 ：
    > 丢弃传统的 CDC 串口驱动，使用 vendor 模式，传输速率更快（基本无影响），<br> 主要是串口驱动容易被系统其它程序干扰，或者容易被系统组件影响，稳定性太差。<br>注意：一旦升级到新固件，只能用最新版本软件，老版本无法识别，只能回退接收器固件才能使用老版本软件。

2. ◼️追踪器固件 V16：
    > 修改新老算法默认方向不一致问题（v15固件按钮重启后会朝右90°）,<br>支持非抗磁模式（之前抗磁开关对v15固件无效，导致不适合用于跳舞），。

**软件**
1. 新增Linux和Android端，主要观察大家是否会出现核心bug，以及改动部分ui的操作逻辑
    > Linux端ui界面会与Windows保持一致，安卓端为重新设计，但操作动线保持与Windows端相近，支持竖屏横屏切换。

2. 3d预览器更换为OGRE
    > 但nvidia显卡驱动可能会把GPU用量归一化显示，导致错误的显示GPU使用率达到20%~40%，AMD显卡无该‘奇妙’显示，有待后续调查和调整。 

3. 固件升级制作为独立窗口
    >v7 ~ v15的固件升级成为很多人都一道门槛，由此改进此窗口。

4. [六轴模式]改名为[地磁辅助]，并且开关反向
    >发现各语言玩家都出现把6轴误认为6个追踪器模式。

5. 动作校准逻辑调整
    >增加[紧急停止]按钮，如果误触校准时可以停下。<br>增加折叠扩展栏，适当调节后校准的倒计时会非常短，支持保留上一次校准的记录（不启用时关闭软件7分钟后过期）。

6. 追踪器敲一敲改为[敲击分配]   
    > 允许玩家自定义敲击宏，自由搭配敲谁、敲打间隔、触发什么快捷键。

7. 增加音量滑条    
    > 方便直接开关软件提示音

8. 消除VMC高度差bug
    > 之前vmc比地面高出一段的bug为地面到hips的高度被错误的 x2 倍输出。

9. 部分使用率高的功能移除[高级设置]的控制 
  

**end.** UI 交互的改进会持续进行，还有很多看到大家的使用感受统计条目有待调整。



#### 2026-02-04 更新: rebocap Release V02 Beta02
1. 更新固件到v15，优化抗磁和6轴算法，抗磁稳定性提升，6轴稳定性提升
   > 动态情况下，比如一直跳舞，并且磁场不好的情况下，还是和6轴性能接近。新固件在磁场良好的情况下，动态跳舞基本能够一直修正（以前的固件则是依赖中间存在静止状态进行修正）
2. 增加延迟自动关机功能，需要升级新的接收器固件。
3. 航向校准重构，同时新增 PC航向校准 功能：
   > 注意：PC航向校准的时候，也是全身A-pose，小臂和手掌也抬起来向前会更好，或者直接做S-Pose也可以，或者坐着把手伸向正前方也行）
4. 软件意外闪退，5分钟内打开，还会自动应用上次校准结果，无需再次动作校准
5. 航向校准时，会重置磁场（直接重置到相对磁场1.0），也就是躺床上的话，会按照校准时刻作为初始磁场来回正。
6. 放开磁场校准限制，简易磁场校准（画8字）默认可展示点击
   > 默认限制8个传感器同时校准，如果data目录新增文件： `data/__no_limit_max_nodes__`，即可放开校准数量限制
7. 修复躺下后脚底运动可能导致人物骨架分离的bug

其它更新：
1. 软件头部显示版本号
2. 修复自动隐藏关机传感器功能不生效的bug
3. 关闭脚底防滑模式下，脚底可以到地面以下，并且移除了IK
4. 解决拔掉接收器后人物姿态冻结的bug
