<!-- ==================== Dropdown Start ==================== -->
<details>
<summary>Vea las versiones de firmware compatibles para el software correspondiente.</summary>
   &emsp;&emsp; Algunas versiones de firmware tienen cambios algorítmicos importantes y son incompatibles con versiones de software más antiguas. <br /> 

   &emsp;&emsp; Al volver a un software antiguo, necesita degradar el firmware en consecuencia.<br /> 

   &emsp;&emsp;&emsp; release_v01 - ◼️rastreador: V6 / V7 , 📡receptor: V6 / V7 <br /> 

   &emsp;&emsp;&emsp; release_v02 beta02 - ◼️rastreador: V15 , 📡receptor: V6 / V7 <br /> 

   &emsp;&emsp;&emsp; (No publicado) release_v02 beta02.1 - ◼️rastreador: V16 , 📡receptor: V8 <br /> 

</details>
<!-- ==================== Dropdown End ==================== -->

- Abra la ventana de registro para ver la versión de firmware real de cada rastreador <br /> 
  (la ventana de registro se encuentra en "Connect and Power Off" en el software).

- Los rastreadores se actualizan de forma inalámbrica 📶 — no se requiere cable de datos USB.<br /> 
  🚫 No actualice el rastreador y el receptor al mismo tiempo.<br /> 
  Si la actualización del rastreador falla, considere apagar la mitad de los rastreadores para estabilizar la carga de datos. Los rastreadores con la versión de firmware correcta en los registros pueden permanecer apagados.

- Si la actualización falla, reinicie el rastreador y haga clic en actualizar nuevamente.<br /> 
  &emsp;&emsp;🟩Luz verde – Parpadeo rápido: El rastreador funciona normalmente<br /> 
  &emsp;&emsp;🟩Luz verde – Parpadeo lento: El rastreador está esperando la señal del receptor<br /> 
  &emsp;&emsp;🟦Luz azul: El rastreador está recibiendo datos de firmware<br /> 
  &emsp;&emsp;🟨Luz amarilla: Actualización fallida (presione manualmente el botón 🔘 para reiniciar, luego actualice nuevamente)<br /> 
  &emsp;&emsp;⬜Luz blanca: Actualización exitosa (generalmente se reinicia automáticamente después de 10s; si no logra reiniciarse automáticamente, se requiere un reinicio manual)<br /> 

- Cuando la actualización del 📡receptor esté completa, desconecte y vuelva a insertar el USB, luego 🔄reinicie el software.

</div>
