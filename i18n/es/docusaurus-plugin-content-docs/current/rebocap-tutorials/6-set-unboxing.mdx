   &emsp;&emsp; Algunas versiones de firmware tienen cambios algorítmicos significativos, lo que las hace incompatibles con el software más antiguo. <br /> 


   &emsp;&emsp; Al volver a una versión de software más antigua, necesita degradar el firmware en consecuencia.<br />

- Abra la ventana de registro (log) para ver la versión de firmware real de cada rastreador <br /> 
(la ventana de registro se encuentra en "Connect & Power Off" en el software).


- Los rastreadores se actualizan de forma inalámbrica 📶 — no se necesita cable USB.<br /> 
🚫 No actualice el rastreador y el receptor al mismo tiempo.<br /> 


- Si la actualización falla, debe reiniciar el rastreador y hacer clic en actualizar nuevamente.<br /> 
&emsp;&emsp;🟩Verde – parpadeo rápido: Rastreador funcionando normalmente<br /> 
&emsp;&emsp;🟩Verde – parpadeo lento: Rastreador esperando señal del receptor<br /> 
&emsp;&emsp;🟦Azul: Rastreador recibiendo datos de firmware<br /> 
&emsp;&emsp;🟨Amarillo: Actualización fallida (presione manualmente el botón 🔘 para reiniciar, luego intente actualizar nuevamente)<br /> 
&emsp;&emsp;⬜Blanco: Actualización exitosa (generalmente se reinicia automáticamente después de 10s; si no, reinicie manualmente)<br />

- Cuando finalice la actualización del 📡receptor, desenchufe y vuelva a enchufar el USB, y 🔄reinicie el software.

<strong style="font-size: 1.15em" class="tutorial-step-title">Pose A</strong><br />
