# Característica de Vista Previa 3D
- **Mostrar vista previa en tiempo real de la captura de movimiento**

  **Instrucciones**
  * Mueve la vista con el botón izquierdo del ratón
  * Arrastra la posición de la cámara con el botón central del ratón, lo que significa arrastrar la vista
  * La rueda del ratón mueve la posición de la cámara hacia adelante y hacia atrás según la dirección actual, lo que se puede usar para ajustar el tamaño de los personajes en la vista
- **Mostrar Rastreador**
    > El área marcada como 1 en la imagen `3d_preview` se utiliza para mostrar el rastreador. Cuando el rastreador está seleccionado, puede mostrar la dirección del rastreador en tiempo real. Al hacer clic en el botón de cuadro se cerrará la vista previa en tiempo real del rastreador.

<a id="how_to_close_3d_preview"></a>

### Cómo Cerrar el 3D para Ahorrar Rendimiento
* Haz clic en el botón en el área 2 de la imagen `3d_preview` para pausar el renderizado, lo que puede ahorrar recursos
* Para cerrar completamente el renderizado 3D: Puedes desactivar directamente el renderizado 3D en la página de configuración, lo que tendrá efecto después de un reinicio, ahorrando memoria y reduciendo significativamente los recursos de CPU y GPU
