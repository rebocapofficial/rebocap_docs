<!-- ==================== Dropdown Start ==================== -->
<details>
<summary>Affichez les versions de firmware prises en charge pour le logiciel correspondant.</summary>
   &emsp;&emsp; Certaines versions de firmware comportent des modifications algorithmiques majeures et sont incompatibles avec les anciennes versions du logiciel. <br /> 

   &emsp;&emsp; Lors du retour à un ancien logiciel, vous devez dégrader le firmware en conséquence.<br /> 

   &emsp;&emsp;&emsp; release_v01 - ◼️tracker : V6 / V7 , 📡récepteur : V6 / V7 <br /> 

   &emsp;&emsp;&emsp; release_v02 beta02 - ◼️tracker : V15 , 📡récepteur : V6 / V7 <br /> 

   &emsp;&emsp;&emsp; (Non publié) release_v02 beta02.1 - ◼️tracker : V16 , 📡récepteur : V8 <br /> 

</details>
<!-- ==================== Dropdown End ==================== -->

- Ouvrez la fenêtre de journal pour afficher la version réelle du firmware de chaque tracker <br /> 
  (la fenêtre de journal est située sous "Connect and Power Off" dans le logiciel).

- Les trackers sont mis à jour sans fil 📶 — aucun câble de données USB n'est requis.<br /> 
  🚫 Ne mettez pas à jour le tracker et le récepteur en même temps.<br /> 
  Si la mise à jour du tracker échoue, envisagez d'éteindre la moitié des trackers pour stabiliser le téléchargement des données. Les trackers avec la bonne version du firmware dans les journaux peuvent rester éteints.

- Si la mise à jour échoue, redémarrez le tracker et cliquez à nouveau sur Mettre à jour.<br /> 
  &emsp;&emsp;🟩Voyant vert – Clignotement rapide : Le tracker fonctionne normalement<br /> 
  &emsp;&emsp;🟩Voyant vert – Clignotement lent : Le tracker attend le signal du récepteur<br /> 
  &emsp;&emsp;🟦Voyant bleu : Le tracker reçoit les données du firmware<br /> 
  &emsp;&emsp;🟨Voyant jaune : Échec de la mise à jour (appuyez manuellement sur le bouton 🔘 pour redémarrer, puis remettez à jour)<br /> 
  &emsp;&emsp;⬜Voyant blanc : Mise à jour réussie (redémarre généralement automatiquement après 10s ; s'il ne redémarre pas automatiquement, un redémarrage manuel est requis)<br /> 

- Lorsque la mise à jour du 📡récepteur est terminée, débranchez et réinsérez l'USB, puis 🔄redémarrez le logiciel.

</div>
