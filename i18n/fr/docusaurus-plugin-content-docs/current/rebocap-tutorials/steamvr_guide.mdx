<strong>Il est recommandé de désactiver 2 options :</strong>
<br />

> <strong>1 - Centrer sur l'espace de jeu (Center to play space)</strong><br />
 Lors d'un double-clic sur le bouton Accueil de la manette gauche pour revenir au bureau VD, le casque dans l'espace SteamVR tourne de 180° vers l'arrière,<br />
ce qui peut amener Rebocap à enregistrer une orientation incorrecte lors de l'étalonnage (Calibration).



> <strong>2 - Émuler les trackers Vive SteamVR (Emulate SteamVR vive trackers)</strong><br />
 Cette fonctionnalité transmet les points de suivi corporel de l'IA du système Quest dans SteamVR, mais provoque des chevauchements de points de suivi et des conflits dans VRChat.<br />
 Si vous souhaitez uniquement activer certains points de suivi personnalisés, vous pouvez utiliser un plugin pour le configurer.<br />
 🌐 [Dépôt GitHub du plugin](https://github.com/DenTechs/Virtual_Desktop_Body_Tracking_Configurator)

### SteamVR
- Désactiver les limites SteamVR<br />
Les limites par défaut restreignent la plage de mouvement maximale des points de suivi comme un mur invisible.<br />
Si le casque VR se désaligne à 2,4 m de hauteur, les trackers peuvent sembler incapables de dépasser la hauteur du casque lorsque vous vous allongez et levez les jambes,<br />
car la hauteur de plafond par défaut de SteamVR est de 2,4 m et les points de suivi ne peuvent pas traverser le plafond.

- Recentrer l'orientation du casque VR à l'avance<br />
Maintenez enfoncé le 'Bouton Accueil de la manette droite' pour réinitialiser l'orientation du système du casque VR,<br />
ce qui réinitialise la flèche de l'horizon virtuel SteamVR pour qu'elle pointe droit devant. Si l'orientation est accidentellement perdue, utilisez cette fonctionnalité pour réaligner le système de coordonnées.

- Pop-up d'invite lors du lancement de jeux<br />
Sélectionnez n'importe quelle configuration de raccourcis de la communauté en arrière-plan,<br />
et après l'avoir activée, l'invite n'apparaîtra plus lors des lancements ultérieurs.

## Impossible de se connecter à SteamVR
Veuillez vérifier les éléments suivants :

<strong> 1 - Cliquez sur Étalonnage pendant que SteamVR est en cours d'exécution.</strong><br />
Si SteamVR n'est pas en cours d'exécution, Rebocap ne peut pas détecter si la VR existe dans le système.

<strong> 2 - Vérifier les pilotes SteamVR.</strong><br />
Ouvrez les enregistrements de la [Fenêtre de journal] de Rebocap, qui vérifient automatiquement au lancement de Rebocap.
Si nécessaire, vous pouvez forcer l'installation des pilotes dans la page [Paramètres].

<strong> 3 - Vérifier les modules complémentaires SteamVR.</strong><br />
Si SteamVR plante de manière inattendue, il désactive souvent de force tous les modules complémentaires.<br />
La réactivation des modules complémentaires Rebocap nécessite de redémarrer SteamVR.

<div style="flex: 1.5; min-width: 250px;">
<strong> Afficher et masquer les points de suivi</strong><br />
 Contrôlez la visibilité des points de suivi dans le logiciel sous [ Set SteamVR Nodes ],<br />
 sans avoir besoin d'opérer dans le menu de gestion de SteamVR.<br />

 <details className="plain-details"><summary>Remarque</summary>
Les trackers ne se connectent pas directement à SteamVR. Les trackers physiques contrôlent le système squelettique, qui crée les points de suivi correspondants et les transmet à SteamVR.<br />
Cela signifie que des points de suivi peuvent toujours être fournis à SteamVR même sans tracker physique sur cette partie du corps.

</details>


</div>

## Points de suivi définis mais le jeu ne reconnaît pas les pieds et la taille

- Certains jeux utilisent l'environnement OpenVR pour identifier le suivi, mais le pilote inclus dans la version actuelle de Rebocap comporte un bug provoquant la non-reconnaissance des trackers, qui ne peuvent pas être reconnus même s'ils sont modifiés dans les paramètres de SteamVR.


Ce bug est en attente de correction par l'équipe dans les futures mises à jour.
