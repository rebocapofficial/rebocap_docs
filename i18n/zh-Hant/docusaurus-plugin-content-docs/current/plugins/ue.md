</div>

重新啟動編輯器，開啟 `編輯 → 外掛`，清單中能看到 <strong>Rebocap - blueprint control</strong>（版本 V3）就表示安裝完成。

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">

</div>
<div style="flex: 1.5; min-width: 250px;">

在 LiveLink 中可以看到對應的 Rebocap 連線埠。

</div>
</div>

</div>

<div class="ue-doc-sec">

<p class="ue-doc-h" role="heading" aria-level="3">2. 在動畫藍圖中使用</p>

<p>以下以 UE 內建的人偶（Mannequin）為例。</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![為角色的骨骼網格體建立動畫藍圖](/img/ue_plugin/guide/03_anim_blueprint.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

在內容瀏覽器中對角色的骨骼網格體按右鍵，選擇 `建立 → 動畫藍圖`，新建或進入該角色的動畫藍圖。

</div>
</div>

<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">設定骨骼映射（Map Data）</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![變數類型選擇 Rebocap Map Data（類別參照）](/img/ue_plugin/guide/04_variable_class.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

在左側變數欄按 `+` 新增一個變數，類型搜尋 `Rebocap`，選擇 `Rebocap Map Data`，再選 `類別參照`（Class Reference）。

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![在預設值中建立 Map Data 資產](/img/ue_plugin/guide/05_map_asset.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

把變數拖進圖表並編譯一次，右側 `預設值` 按 `+`，建立一個 Map Data 資產。

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Rebocap 骨骼映射視窗](/img/ue_plugin/guide/06_bone_mapping.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

在映射視窗中逐項填入角色對應的骨骼名稱。`選擇骨骼預設` 可一鍵填入 UE 預設命名；若角色骨骼命名不同，請開啟骨架視窗查看後複製過來。

</div>
</div>

</div>

<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">重要 · 把角色調整為 T-Pose</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![在動畫藍圖中加入 A-Pose to T-Pose 節點](/img/ue_plugin/guide/07_a2t_node.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

角色本身已是 T-Pose 的話可跳過這一步。否則使用 `Rebocap A-Pose to T-Pose` 節點，直接在動畫藍圖裡把角色調整為 T-Pose。

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![A-Pose to T-Pose 節點的 Retarget Asset 設定](/img/ue_plugin/guide/08_a2t_details.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

此節點能自動辨識部分常見骨骼，也可手動指定 `Retarget Asset`；其他類型的 A-Pose 可以手動微調，讓手、腿在視覺上明確呈 T-Pose。

</div>
</div>

</div>

<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">設定動捕連線</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![搜尋並加入 Rebocap Body Pose 節點](/img/ue_plugin/guide/09_body_pose_node.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

在動畫圖表中按右鍵搜尋 `reb`，加入 `Rebocap Body Pose` 節點。

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![A-Pose to T-Pose 與 Body Pose 的串接順序](/img/ue_plugin/guide/10_node_chain.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

若使用了 `A-Pose to T-Pose` 節點，請把它放在 `Body Pose` 的前一級；兩個節點的 `Retarget Asset` 接同一份 Map Data。

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![連線成功後兩邊的動作一致](/img/ue_plugin/guide/11_connected.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

按下編譯後，Rebocap 軟體提示已接收到骨架資料，且兩邊的 3D 預覽動作一致，就表示連線成功。

</div>
</div>

<p class="ue-doc-h" role="heading" aria-level="3" id="rebocap-body-pose">Rebocap Body Pose</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Rebocap Body Pose 節點](/img/ue_plugin/nodes/body_pose_node.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

把 Rebocap 的 24 個動捕節點即時驅動到角色骨骼上，是外掛的主節點：讀取 LiveLink 主題，經骨骼映射資產換算後寫入姿勢。

把它接在 `Output Pose` 之前，指定 `Retarget Asset`，角色即跟隨動捕。

</div>
</div>

<p style="margin: 6px 0 0; font-size: 13px; color: var(--ifm-color-emphasis-600);">圖 2：正常收流時標題會顯示 [60 Hz]、[Connected]。</p>

<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">引腳</p>

| 引腳 | 類型 | 預設 | 說明 |
| --- | --- | --- | --- |
| `Auto Submit Skeleton Data` | bool | true | 首次連線時把角色 T-Pose 骨架（24 骨 + 腳底點）回傳給 Rebocap |
| `Connect Rebocap` | bool | true | 節點是否自動連線；關閉後只能由面板或藍圖手動連線 |
| `Enable Frame Interpolation` | bool | false | 渲染影格率高於動捕影格率時做插值，消除階梯感 |
| `Interpolation Speed` | float | 45 | 插值速度（1–120），越大越跟手 |
| `Hold Pose On Dropout` | bool | true | 掉包時保持最後有效姿勢，避免閃回 T-Pose |
| `Show Viewport Debug HUD` | bool | false | 左上角顯示動捕影格率、視口 FPS 與連線狀態 |
| `Retarget Asset` | class | `RebocapMapData` | 骨骼映射資產 |

</div>

<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">細節面板</p>

| 參數 | 預設 | 說明 |
| --- | --- | --- |
| `LiveLink Subject Name` | rebocap | LiveLink 主題名，多裝置／多實例時區分 |
| `Dropout Timeout (s)` | 2.0 | 保持最後姿勢的最長時間 |
| `Stale Frame Timeout (s)` | 0.25 | 影格齡超過此值視為掉格，避免斷線後永久凍結 |
| `Resume Blend (s)` | 0.15 | 掉線恢復時的過渡時間 |
| `Throttle Skeleton Registration` | false | 實驗項：骨架註冊最多 2 秒一次 |
| `Zero-Alloc Static Subject` | false | 實驗項：跳過重複的靜態骨架配置 |
| `Optimize Frame Evaluation` | false | 實驗項：快取 LiveLink 角色，降低鎖競爭 |
| `Show Controlled Bones` | true | 預覽視口高亮被驅動的骨骼 |
| `Joint Color` / `Link Color` | 青 / 洋紅 | 關節點與連線顏色 |
| `Joint Radius` / `Link Thickness` | 2.2 / 1.6 | 關節點半徑與連線粗細 |

</div>

<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">使用步驟</p>

1. 動畫藍圖裡按右鍵搜尋 `Rebocap Body Pose`；
2. 接到 `Output Pose` 之前；
3. 新建或指定一份 `RebocapMapData`，填好 24 根骨骼；
4. 編譯，確認只有預期內的「找不到骨骼」警告；
5. PIE 執行，控制面板顯示約 60 Hz 即正常。

</div>

<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">注意</p>

- 預設姿勢必須是 **T-Pose**；A-Pose 角色請在前一級接 `Rebocap A-Pose to T-Pose`。
- `Auto Submit Skeleton Data` 的腳底頂點只在編輯器中取得，打包後接地略差。
- 不指定 `Retarget Asset` 時使用內建預設，骨骼名不同就必須自建資產。

</div>

</div>

<div class="ue-doc-sec">

<p class="ue-doc-h" role="heading" aria-level="3" id="rebocap-a-pose-to-t-pose">Rebocap A-Pose to T-Pose</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Rebocap A-Pose to T-Pose 節點](/img/ue_plugin/nodes/a2t_node.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

把 A-Pose 基礎姿勢轉成 T-Pose，供 `Rebocap Body Pose` 正確驅動。適用於 MetaHuman、VRoid、MMD、Mixamo 等預設 A-Pose 的角色。

</div>
</div>

<p style="margin: 6px 0 0; font-size: 13px; color: var(--ifm-color-emphasis-600);">圖 3：`Alpha` 控制轉換的混合權重。</p>

<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">引腳</p>

| 引腳 | 類型 | 預設 | 說明 |
| --- | --- | --- | --- |
| `Base Pose` | Pose | — | 來自前一級的基礎姿勢 |
| `Retarget Asset Override (Pin)` | class | 空 | 選用：用引腳暫時覆蓋映射資產 |
| `Alpha` | float | 1.0 | 混合權重：0 不修改，1 完全轉換 |

</div>

<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">細節面板</p>

| 參數 | 預設 | 說明 |
| --- | --- | --- |
| `Select Preset Template` | UE5 Manny/Quinn/MetaHuman | 一鍵填入 20 骨偏移；另有 MMD（約 40°）、VRoid/VRM（約 40°）、Mixamo（約 45°）、Custom |
| `Symmetrical Edit` | true | 只改左側，右側自動鏡像 |
| `Invert Roll / Pitch / Yaw` | false | 鏡像時依軸翻轉 |
| `Retarget Asset` | 空 | 與 `Rebocap Body Pose` 共用 |
| `Use Retarget Asset Bones` | true | 每次重新整理時用資產覆蓋骨骼名 |

<p class="ue-doc-h" role="heading" aria-level="3" id="parameter-quick-reference">參數速查與常見問題</p>

| 現象 | 常見原因 | 處理 |
| --- | --- | --- |
| 角色不動 | 未指定 `Retarget Asset`，或映射為空 | 新建 `RebocapMapData` 並填滿 24 骨 |
| 報找不到 `spine_04` / `spine_05` | UE4 人偶只有 3 節脊椎 | 換成 UE4 預設（spine_01/02/03） |
| 抖動、階梯感 | 渲染影格率高於動捕影格率 | 開啟 `Enable Frame Interpolation` |
| 斷線時閃一下 | 舊版本自動重連 | 升級到 V3 |
| 斷線後姿勢卡住 | 舊版本一直回傳最後一格 | 升級到 V3（`Stale Frame Timeout`） |
| 恢復瞬間跳變 | 首格直接賦值 | 調大 `Resume Blend (s)` 至 0.15–0.3 |
| 自訂連接埠連不上 | 動捕端未監聽 | 約 4.5 秒自動回退 7690 |
