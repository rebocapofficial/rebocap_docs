<p class="ue-doc-h" role="heading" aria-level="3">1. UE 프로젝트에 플러그인 설치</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![rebocap 폴더를 프로젝트의 Plugins 폴더에 넣기](/img/ue_plugin/guide/01_install_plugins.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

플러그인 압축 파일의 압축을 풀고, 안에 있는 `rebocap` 폴더를 프로젝트 루트의 `Plugins` 폴더에 통째로 넣습니다. 프로젝트에 `Plugins` 폴더가 없으면 새로 만드세요.

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![에디터 플러그인 목록에 표시된 Rebocap 플러그인](/img/ue_plugin/guide/02_plugin_list.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

에디터를 다시 시작하고 `Edit → Plugins`를 열었을 때 목록에 <strong>Rebocap - blueprint control</strong>(버전 V3)이 보이면 설치가 끝난 것입니다.

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![LiveLink에서 확인한 Rebocap 연결 포트](/img/ue_plugin/guide/02_1_livelink.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

LiveLink에서 해당 Rebocap 연결 포트를 확인할 수 있습니다.

</div>
</div>

</div>

<div class="ue-doc-sec">

<p class="ue-doc-h" role="heading" aria-level="3">2. 애니메이션 블루프린트에서 사용</p>

<p>아래에서는 UE 기본 마네킹(Mannequin)을 예로 듭니다.</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![캐릭터 스켈레톤 메시로 애니메이션 블루프린트 만들기](/img/ue_plugin/guide/03_anim_blueprint.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

콘텐츠 브라우저에서 캐릭터의 스켈레톤 메시를 우클릭하고 `Create → Anim Blueprint`를 선택한 뒤, 해당 캐릭터의 애니메이션 블루프린트를 새로 만들거나 엽니다.

</div>
</div>

<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">뼈대 매핑 설정(Map Data)</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![변수 유형으로 Rebocap Map Data(클래스 참조) 선택](/img/ue_plugin/guide/04_variable_class.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

왼쪽 변수 패널에서 `+`를 눌러 변수를 하나 만들고, 유형 검색란에 `Rebocap`을 입력해 `Rebocap Map Data`를 고른 다음 `Class Reference`(클래스 참조)를 선택합니다.

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![기본값에서 Map Data 에셋 만들기](/img/ue_plugin/guide/05_map_asset.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

변수를 그래프로 끌어다 놓고 한 번 컴파일한 뒤, 오른쪽 `Default Value`에서 `+`를 눌러 Map Data 에셋을 새로 만듭니다.

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Rebocap 뼈대 매핑 창](/img/ue_plugin/guide/06_bone_mapping.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

매핑 창에서 캐릭터에 해당하는 뼈대 이름을 하나씩 채웁니다. `Select Bone Preset`을 누르면 UE 기본 뼈대 이름이 한 번에 채워지고, 캐릭터의 뼈대 이름이 다르다면 스켈레톤 창을 열어 확인한 뒤 그대로 복사해 넣으면 됩니다.

</div>
</div>

</div>

<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">중요 · 캐릭터를 T-Pose로 맞추기</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![애니메이션 블루프린트에 A-Pose to T-Pose 노드 추가](/img/ue_plugin/guide/07_a2t_node.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

캐릭터 자체가 이미 T-Pose라면 이 단계는 건너뛰어도 됩니다. 그렇지 않다면 `Rebocap A-Pose to T-Pose` 노드로 애니메이션 블루프린트 안에서 캐릭터를 바로 T-Pose로 맞춥니다.

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![A-Pose to T-Pose 노드의 Retarget Asset 설정](/img/ue_plugin/guide/08_a2t_details.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

이 노드는 흔히 쓰이는 뼈대를 자동으로 인식하며 `Retarget Asset`을 직접 지정할 수도 있습니다. 그 밖의 A-Pose는 팔과 다리가 시각적으로 T-Pose임이 분명해질 때까지 직접 미세 조정하면 됩니다.

</div>
</div>

</div>

<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">모션 캡처 연결 설정</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Rebocap Body Pose 노드 검색 및 추가](/img/ue_plugin/guide/09_body_pose_node.png)

<div style="flex: 1.5; min-width: 250px;">

애니메이션 그래프에서 우클릭해 `reb`를 검색하고 `Rebocap Body Pose` 노드를 추가합니다.

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![A-Pose to T-Pose와 Body Pose의 연결 순서](/img/ue_plugin/guide/10_node_chain.png)

</div>

</div>
</div>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

컴파일한 뒤 Rebocap 소프트웨어에 뼈대 데이터를 수신했다는 알림이 뜨고 양쪽 3D 프리뷰 동작이 일치하면 연결에 성공한 것입니다.

<p style="margin: 6px 0 0; font-size: 13px; color: var(--ifm-color-emphasis-600);">그림 1: 모션 캡처 데이터가 캐릭터에 도달하는 과정.</p>

<div class="ue-doc-sec">

<p class="ue-doc-h" role="heading" aria-level="3" id="rebocap-body-pose">Rebocap Body Pose</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Rebocap Body Pose 노드](/img/ue_plugin/nodes/body_pose_node.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

Rebocap의 모션 캡처 노드 24개를 캐릭터 뼈대에 실시간으로 구동하는 플러그인의 주 노드입니다. LiveLink 서브젝트를 읽어 뼈대 매핑 에셋으로 변환한 뒤 포즈에 기록합니다.

`Output Pose` 앞에 연결하고 `Retarget Asset`을 지정하면 캐릭터가 모션 캡처를 따라갑니다.

</div>
</div>
<p style="margin: 6px 0 0; font-size: 13px; color: var(--ifm-color-emphasis-600);">그림 2: 정상적으로 수신 중일 때 제목에 [60 Hz], [Connected]가 표시됩니다.</p>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">핀</p>

| 핀 | 유형 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `Auto Submit Skeleton Data` | bool | true | 최초 연결 시 캐릭터의 T-Pose 뼈대(뼈대 24개 + 발바닥 접점)를 Rebocap으로 돌려보냅니다 |
| `Connect Rebocap` | bool | true | 노드의 자동 연결 여부입니다. 끄면 패널이나 블루프린트에서만 수동으로 연결할 수 있습니다 |
| `Enable Frame Interpolation` | bool | false | 렌더 프레임레이트가 모션 캡처 프레임레이트보다 높을 때 보간해 계단 현상을 없앱니다 |
| `Interpolation Speed` | float | 45 | 보간 속도(1–120)로, 값이 클수록 더 민첩하게 따라갑니다 |
| `Hold Pose On Dropout` | bool | true | 패킷이 유실될 때 마지막 유효 포즈를 유지해 T-Pose로 되돌아가는 현상을 막습니다 |
| `Show Viewport Debug HUD` | bool | false | 왼쪽 위에 모션 캡처 프레임레이트, 뷰포트 FPS, 연결 상태를 표시합니다 |
| `Retarget Asset` | class | `RebocapMapData` | 뼈대 매핑 에셋 |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">디테일 패널</p>

| 파라미터 | 기본값 | 설명 |
| --- | --- | --- |
| `LiveLink Subject Name` | rebocap | LiveLink 서브젝트 이름으로, 다중 장비나 다중 인스턴스를 구분할 때 씁니다 |
| `Dropout Timeout (s)` | 2.0 | 마지막 포즈를 유지하는 최대 시간입니다 |
| `Stale Frame Timeout (s)` | 0.25 | 프레임 경과 시간이 이 값을 넘으면 프레임 유실로 간주합니다. 이 값이 없으면 연결이 끊긴 뒤 포즈가 영원히 멈춥니다 |
| `Resume Blend (s)` | 0.15 | 연결이 복구될 때 전환에 쓰는 시간입니다 |
| `Throttle Skeleton Registration` | false | 실험 항목: 뼈대 등록을 최대 2초에 한 번만 수행합니다 |
| `Zero-Alloc Static Subject` | false | 실험 항목: 중복되는 정적 뼈대 할당을 건너뜁니다 |
| `Optimize Frame Evaluation` | false | 실험 항목: LiveLink 롤을 캐시해 락 경합을 줄입니다 |
| `Show Controlled Bones` | true | 프리뷰 뷰포트에서 구동되는 뼈대를 하이라이트합니다 |
| `Joint Color` / `Link Color` | 시안 / 마젠타 | 관절점과 연결선 색상입니다 |
| `Joint Radius` / `Link Thickness` | 2.2 / 1.6 | 관절점 반지름과 연결선 두께입니다 |

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">사용 단계</p>

1. 애니메이션 블루프린트에서 우클릭해 `Rebocap Body Pose`를 검색합니다.
2. `Output Pose` 앞에 연결합니다.
3. `RebocapMapData`를 새로 만들거나 지정하고 뼈대 24개를 모두 채웁니다.
4. 컴파일한 뒤, 예상한 "뼈대를 찾을 수 없음" 경고만 나오는지 확인합니다.
5. PIE로 실행해 제어 패널에 약 60 Hz가 표시되면 정상입니다.

</div>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">주의</p>

- 기본 포즈는 반드시 <strong>T-Pose</strong>여야 하며, A-Pose 캐릭터는 이 노드 앞 단계에 `Rebocap A-Pose to T-Pose`를 연결하세요.
- `Auto Submit Skeleton Data`의 발바닥 정점은 에디터에서만 가져올 수 있어 패키징 후에는 접지가 다소 떨어집니다.
- `Retarget Asset`을 지정하지 않으면 내장 프리셋을 사용하므로, 뼈대 이름이 다르면 직접 에셋을 만들어야 합니다.

</div>

</div>
<div class="ue-doc-sec">

<p class="ue-doc-h" role="heading" aria-level="3" id="rebocap-a-pose-to-t-pose">Rebocap A-Pose to T-Pose</p>

<div style="display: flex; flex-direction: row; gap: 20px; flex-wrap: wrap; align-items: center; margin: 15px 0;">
<div style="flex: 1; min-width: 250px; text-align: center;">

![Rebocap A-Pose to T-Pose 노드](/img/ue_plugin/nodes/a2t_node.png)

</div>
<div style="flex: 1.5; min-width: 250px;">

A-Pose 기본 포즈를 T-Pose로 변환해 `Rebocap Body Pose`가 올바르게 구동되도록 합니다. MetaHuman, VRoid, MMD, Mixamo처럼 기본 포즈가 A-Pose인 캐릭터에 적합합니다.

<p style="margin: 6px 0 0; font-size: 13px; color: var(--ifm-color-emphasis-600);">그림 3: `Alpha`가 변환의 블렌드 가중치를 제어합니다.</p>
<div class="ue-doc-subsec">

<p class="ue-doc-sub" role="heading" aria-level="4">핀</p>

| 핀 | 유형 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `Base Pose` | Pose | — | 앞 단계에서 넘어온 기본 포즈입니다 |

| `Alpha` | float | 1.0 | 블렌드 가중치로, 0이면 수정하지 않고 1이면 완전히 변환합니다 |

<p class="ue-doc-sub" role="heading" aria-level="4">디테일 패널</p>

| --- | --- | --- |

| `Invert Roll / Pitch / Yaw` | false | 미러링할 때 축 단위로 뒤집습니다 |
| `Retarget Asset` | 없음 | `Rebocap Body Pose`와 공유합니다 |
| `Use Retarget Asset Bones` | true | 새로 고칠 때마다 에셋의 뼈대 이름으로 덮어씁니다 |

- 노드를 선택하면 프리뷰 뷰포트에서 조정된 뼈대가 하이라이트됩니다(A2T는 청록/금색).

<p class="ue-doc-h" role="heading" aria-level="3" id="parameter-quick-reference">파라미터 빠른 참조와 자주 발생하는 문제</p>

| 증상 | 흔한 원인 | 해결 |
| --- | --- | --- |
| 캐릭터가 움직이지 않음 | `Retarget Asset`을 지정하지 않았거나 매핑이 비어 있음 | `RebocapMapData`를 새로 만들고 뼈대 24개를 모두 채웁니다 |
| `spine_04` / `spine_05`를 찾을 수 없다는 경고 | UE4 마네킹은 척추 뼈대가 3개뿐 | UE4 프리셋으로 바꿉니다(spine_01/02/03) |
| 떨림, 계단 현상 | 렌더 프레임레이트가 모션 캡처 프레임레이트보다 높음 | `Enable Frame Interpolation`을 켭니다 |
| 연결을 끊을 때 한 번 튐 | 구버전이 자동으로 다시 연결 | V3로 업그레이드합니다 |
| 연결이 끊긴 뒤 포즈가 멈춤 | 구버전이 마지막 프레임을 계속 반환 | V3로 업그레이드합니다(`Stale Frame Timeout`) |
| 복구되는 순간 튐 | 첫 프레임을 한 번에 적용 | `Resume Blend (s)`를 0.15–0.3으로 늘립니다 |
| 사용자 지정 포트로 연결되지 않음 | 모션 캡처 쪽에서 해당 포트를 수신하지 않음 | 약 4.5초 뒤 7690으로 자동 복귀합니다 |
| 패키징 후 발바닥이 떠 있음 | 런타임에서 발바닥 정점을 가져올 수 없음 | 알려진 제한 사항입니다 |
