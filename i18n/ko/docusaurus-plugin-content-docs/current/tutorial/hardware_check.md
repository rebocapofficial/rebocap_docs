## 언박싱 확인&#x20;

- 본 제품은 현재 서랍형 컬러 상자 + 일반 판지 포장을 사용하며, 완충력을 더하기 위해 6개 면 모두에 에어 쿠션을 둘러쌌습니다.
- 제품 목록

  - 트래커 x 15

    > 각 트래커의 밑면에는 해당하는 숫자 코드와 신체 부위가 표시된 라벨이 있습니다. 예: 왼쪽 허벅지는 1번, 왼쪽 종아리는 3번. [교체 기능](../ui_help_doc/remap#trackerreplace)을 사용하지 않는 한 트래커의 위치는 고정되어 있습니다.
  - 리시버 x 1
  - 충전 베이스 x 1

    > 보관용으로 사용할 수 있으며, 배터리 자체는 포함되어 있지 않습니다.

:::danger 12V 이상의 전원 어댑터(예: 24V 전원 어댑터)를 사용하면 과전압으로 인해 충전 보드가 타버릴 수 있습니다!!!

:::

- 전원 어댑터 x 1

  > 12V 2A, 프리볼트, 110V 및 220V와 호환 가능.

- 스트랩 x 15 + 보관용 메쉬 백 x 1

  1. 100cm \* 2
  2. 60cm \* 3
  3. 40cm \* 6
  4. 25cm \* 4

- 서랍형 컬러 상자 x 1

- \[사은품] 신체 부위 스티커 15장 x 1

  > 각 트래커의 위치를 확인하는 데 도움을 주어, 착용 후 올바르게 착용했는지 쉽게 확인할 수 있습니다.

- \[사은품] 플라스틱 줄자 x 1

- \[선택적 추가 항목] 퀵 릴리즈(Quick Release) x 15

  > 중국 본토에서는 선택적 액세서리입니다(공식 타오바오 상점에서 구매 가능). 중국 본토 외 지역의 경우, 긴 배송 거리로 인해 일부 사용자가 퀵 릴리즈의 기능을 이해하지 못하거나 구매를 잊어버려 두 번째 구매 시 추가 배송비가 발생하는 것을 방지하기 위해 본 제품과 함께 필수 액세서리로 판매됩니다.

- 제품 언박싱 비디오

  > 충전 상자 뚜껑을 여는 방법은 비디오의 13초를 참조하세요. 엄지손가락으로 상자 상단의 스프링 버튼을 누르고 다른 손으로 뚜껑을 엽니다.

- 하드웨어 품질에 대해

  1. 트래커의 상단 덮개와 하단 덮개 사이에 약간의 틈이 있고 덮개 간 약간의 어긋남이 있는 것은 정상적인 현상입니다.
  2. 대형 충전 상자에서 중간 지지 부품의 사출 성형 물 배출구가 외관 표면에 남아 있어 버클 옆에 약간의 틈과 결함이 발생합니다.
  3. 리시버의 USB 인터페이스는 공장에서부터 약간 기울어져 있으며, 이는 사용에 영향을 미치지 않습니다.
  4. 플라스틱 쉘은 현재 UV 코팅이 되어 있지 않아 흠집이 남기 쉽습니다.
  5. 트래커 배터리 간에 일정한 용량 오차가 있는 것은 정상입니다. 사용 시간이 기준입니다 \[배터리 비율은 참고용으로만 사용할 수 있으며 평가 지표로 사용할 수 없습니다].

- 충전 베이스의 버튼

  <img src="/img/box_button.png" alt="switch" />

  1. 트래커의 불을 켜려면 한 번 누르세요.
  2. 전원을 끄려면 3~4초 동안 길게 누르세요.
  3. 재설정 빈도 \[일반적으로 필요하지 않음]

     - 트래커의 불을 켠 후 8~10초 동안 길게 눌렀다 떼면 트래커의 파란색 표시등이 깜박이며 초기화 상태로 들어갑니다. 다시 8~10초 동안 길게 눌렀다 떼어 재설정을 확인하면 녹색 표시등이 깜박입니다.

## 충전 및 사용 시간 안내

- 처음 수령 시 충전이 가능한지 확인해야 합니다. 정상적으로 어댑터를 연결한 후에는 모든 트래커에 빨간불이 켜지고 완전히 충전되면 녹색으로 바뀝니다.
- 불이 켜지지 않는 트래커가 있으면 배송 중 헐거워졌는지 확인하고 해당 트래커를 다시 삽입하세요. 어느 트래커에도 불이 들어오지 않으면 전원 어댑터가 연결되어 있는지 확인하세요.
- 일반적으로 완전히 충전하는 데 약 2시간이 걸리며 사용 시간은 약 30시간입니다.


:::info 사용 시간 및 충전 안내
1. 사용 시간은 주변 온도와 관련이 있으며, 낮은 온도는 사용 시간을 단축시킵니다.
2. 개별 노드가 정상적으로 종료되지 않으면 전력이 계속 소비되어 다른 트래커에 비해 사용 시간이 크게 차이 날 수 있습니다.
3. 완전히 충전된 후 트래커를 제거했다가 다시 꽂으면 다시 빨간불이 표시되는데, 이는 정상입니다. 전통적인 휴대폰이나 기타 전기 제품의 충전과 유사하게, 완전히 충전된 후 제거하고 다시 충전하면 단기간 세류 충전(trickle charging)을 수행할 수 있습니다.
:::

- <p>드문 경우지만 완전히 충전한 후에도 일부 트래커가 녹색으로 바뀌지 않을 수 있습니다. 연결 후 소프트웨어에 표시되는 배터리 수준을 참조하세요!</p>
- <p>장기간 사용하지 않을 때는 배터리 수명에 영향을 미치지 않도록 2~3개월마다 방전 및 재충전하는 것이 좋습니다! 예를 들어, VR 사용자는 5~7개의 유휴 포인트가 있을 수 있는데, 향후 손상된 포인트가 발생하면 이를 팔뚝용으로 교체할 수 있으므로 배터리를 잘 관리하는 것이 좋습니다.</p>

> 참고: 사용 시간은 인간의 운동 상태와 무관합니다. 한 번 연결되면 움직임의 속도와 관계없이 전류 소비량은 일정하게 유지됩니다.

## 트래커 상태 설명

|            |     대기 상태    |   연결 끊김 상태  | 연결 상태 |                    배터리 부족                   |   펌웨어 업데이트   | 펌웨어 업데이트 성공 |
| :--------: | :------------------: | :-------------------: | :-------------: | :----------------------------------------------: | :-----------------: | :------------------------: |
| RGB 상태 | 숨쉬기 표시등 (3S) | 숨쉬기 표시등 (10S) |  빠르게 깜박임  | 빨간색 깜박임<br />3번 깜박인 후 전원 종료 | 파란색 깜박임 |    흰색 깜박임    |

- 트래커의 불이 켜지면 대기 모드로 들어갑니다. 대기 모드에서는 숨쉬기 표시등이 30초 동안 계속 깜박이며 10분 동안 연결되지 않으면 자동으로 전원이 꺼집니다.
- 리시버에 전원이 공급되는 한 트래커는 연결 상태가 되며 연결 상태에서는 자동으로 전원이 꺼지지 않습니다.

:::warning 소프트웨어를 닫아도 자동으로 종료되지 않습니다.
어떤 경우에는 종료 실패로 인해 전력이 계속 소비될 수도 있습니다!
:::



- 리시버의 전원이 꺼지면 트래커는 다시 대기 모드로 전환됩니다.
- 트래커가 자동으로 꺼지지 않는 경우 리시버에 전원이 공급되면 즉시 연결 상태가 됩니다.
