# 센서 개요

아래 그림과 같이 녹색은 센서가 해당 관절에 연결되어 있음을 나타내고 회색은 연결되지 않았음을 나타냅니다. 이미지의 왼쪽 부분은 인체의 왼쪽을 나타냅니다; 예를 들어, 아래 이미지에서 왼쪽 발의 센서가 연결되지 않았고 오른쪽 아래 다리의 센서도 연결되지 않았습니다.

## 센서 교체 기능
여기에서 센서 포인트를 끌어다 놓아 센서를 재구성할 수 있습니다.

:::warning 교체 후, 활성화되지 않으면 캘리브레이션 실패를 초래합니다.


많은 사용자가 실수로 센서를 끌어옵니다, 예를 들어 왼쪽 손을 왼쪽 허벅지로 끌어오지만 캘리브레이션 중 왼쪽 손이 활성화되지 않으면, 왼쪽 허벅지가 활성화되지 않았기 때문에 캘리브레이션 실패 메시지가 표시됩니다!!! 
드래그한 후, 교체된 포인트는 활성화 여부와 관계없이 적용되지 않습니다.

:::

### 다른 신체 부위로 교체할 수 있는 지점
   * 왼손 (Node 13)
   * 오른손 (Node 14)
   * 왼쪽 하박 (Node 11)
   * 오른쪽 하박 (Node 12)


### 교체 가능한 부위
   전체


### 특수 기능
   * 어깨 위치로 교체
    > 어깨 부분을 더 유연하게 만들고 싶다면 어깨 위치로 교체할 수 있지만 스트랩에 대한 요구 사항이 더 높으며 자체적으로 해결해야 합니다.


### 교체 예시
아래 그림과 같이 왼손과 오른손의 4개 지점이 모두 교체되었으며 다음 부위가 교체되었습니다:
* 왼쪽 어깨
* 오른쪽 어깨
* 왼쪽 하퇴
  > 왼쪽 하퇴가 교체 후 활성화되지 않아 캘리브레이션 실패가 발생합니다!!!
* 오른쪽 하퇴
