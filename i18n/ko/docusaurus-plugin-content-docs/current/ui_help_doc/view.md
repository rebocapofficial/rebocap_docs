# 3D 미리보기 기능
- **모션 캡처의 실시간 미리보기 표시**

  **사용 방법**
  * 마우스 왼쪽 버튼으로 뷰를 이동합니다
  * 마우스 가운데 버튼으로 카메라 위치를 드래그합니다, 이는 뷰를 드래그하는 것을 의미합니다
  * 마우스 휠은 현재 방향에 따라 카메라 위치를 앞뒤로 이동시키며, 이를 사용하여 뷰의 캐릭터 크기를 조정할 수 있습니다
- **트래커 표시**
    > 이미지 `3d_preview`에 1로 표시된 영역은 트래커를 표시하는 데 사용됩니다. 트래커를 선택하면 트래커 방향을 실시간으로 표시할 수 있습니다. 상자 버튼을 클릭하면 트래커의 실시간 미리보기가 닫힙니다.

<a id="how_to_close_3d_preview"></a>

### 성능 절약을 위해 3D를 닫는 방법
* 리소스 절약을 위해 렌더링을 일시 중지하려면 이미지 `3d_preview`의 영역 2에서 버튼을 클릭하십시오
* 3D 렌더링을 완전히 닫으려면: 구성 페이지에서 3D 렌더링을 직접 끌 수 있으며 재시작 후 적용됩니다, 메모리를 절약하고 CPU 및 GPU 리소스를 크게 줄입니다
