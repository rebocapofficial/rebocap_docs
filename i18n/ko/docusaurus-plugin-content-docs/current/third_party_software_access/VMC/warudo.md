# warudo 연동
VMC 수신만 구성하고 다른 설정은 변경하지 마십시오. 변경된 경우 재설정해 주세요. 먼저 rebocap만 연결된 상태에서 효과를 확인합니다. 또한 골격을 rebocap에 업로드해야 합니다. [여기를 참조하세요](README#vmc_instroction). 그렇지 않으면 발이 떠 있거나 전반적인 모션 트래킹에 심각한 문제가 발생하기 쉽습니다.

아래는 스크린샷 순서도로 매우 간단합니다. VMC 수신의 경우 이미지의 1과 2의 주석 외에, 변경한 구성이 확실하지 않은 경우 수정하지 마십시오!

세 번째 이미지의 주석 정보는 직접 수정해야 합니다:

1. 특정 VMC 수신을 선택한 후 캐릭터 매핑
2. VMC 포트 번호는 rebocap의 vmc 출력 포트 번호와 일치해야 합니다. [구체적인 구성은 여기를 참조하세요](../../ui_help_doc/control/connect#cal_pc_panel)

   - [PC 패널에서] VMC 출력 스위치를 켜야 합니다.
   - 이 페이지의 이미지를 확대할 수 없는 경우 새로고침하고 클릭하여 확대하세요.
   - 구성이 동일한데도 여전히 모션 캡처를 완료할 수 없는 경우 얼굴 캡처 및 손 캡처와 같은 다른 모든 warudo 구성을 제거한 다음 위의 세 이미지에 따라 연동을 구성해 보세요. 그렇지 않으면 충돌로 인해 모션 캡처가 불가능할 수 있으며, 충돌은 직접 해결하거나 warudo의 공식 지원 센터에 문의하여 해결해야 합니다.
